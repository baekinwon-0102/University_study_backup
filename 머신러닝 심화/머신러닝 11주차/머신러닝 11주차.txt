## 신경망 개념

순전파
- 입력층에서 출력층 방향으로 연산 진행되면서 최종 출력값이 도출되는 과정

손실함수
- 예측값과 실제값 차이를 구하는 함수
  - 두 값의 차이가 클 수록 손실함수의 값은 커짐
  - 두 값의 차이가 작을수록 손실함수 값도 작아짐

역전파
- 오차예측값과 실제값의 차이를 역방향으로 전파시키면서
  (출력층 -> 은닉층 -> 입력층) 가중치를 업데이트하는 것
- 경사 하강법을 이용해 오차를 줄이는 방향으로 가중치 수정
- 가중치 수정할 때 순전파에서 계산한 결과 y=f(x)의 편미분값을
  오차에 곱해 출력층 -> 은닉층 -> 입력층 순서로 전달함

오차 계산
- MSE(Mean Squared Error)
  - 예측값과 실제값의 차이인 오차들의 제곱에 대한 평균
  - 수식: sigma(예측값 - 실제값)^2 / n
  - 장점: 직관적이고 단순
  - 단점: 오류를 제곱하기 때문에 1 미만 오류는 더 작아지고 그 이상 오류는 더 커지는 값의
    왜곡이 발생, 스케일에 의존적
- MAE
  - 예측값과 실제값의 차이인 오차들의 절댓값에 대한 평균
  - 수식: sigma(|예측값 - 실제값|)/n
  - 장점: 매우 직관적인 지표
  - 단점: 스케일에 의존적 

옵티마이저
- 딥러닝에서 학습 속도를 빠르고 안정적이게 만드는 것
- 전체 데이터(전체 배치)를 가지고 매개변수(가중치, 편향)의 값을 조정할 수 있고,
  정해준 양의 데이터(미니 배치)만 가지고 매개변수의 값을 조정할 수 있음
- 배치(Batch): 가중치 등 매개변수 값을 조정하기 위해 사용하는 데이터의 양
- 일반적으로 전체 데이터를 한번에 학습하게 되면 계산량이 많아질 뿐만 아니라
  속도도 느려질 수 있기 때문에 미니 배치를 이용한 학습을 함

경사 하강법
- 1차 미분계수를 이용해 함수의 최소값을 찾아가는 iterative한 방법
- 함수 값이 낮아지는 방향으로 독립 변수 값을 변형시켜가면서 최종적으로 최소 함수 값을
  갖도록 하는 독립 변수 값을 찾는 방법

경사 하강법 수식
- 미분 통해 구해진 기울기 활용
- 기울기가 양수라면
  - x값이 커질 수록 함수 값이 커진다는 것을 의미
  - 최소값을 찾고 싶으면 x값이 작아지게 하면 됨 (왼쪽으로 이동)
- 기울기가 음수라면
  - x값이 커질 수록 함수 값이 작아진다는 것을 의미
  - 최소값 찾고 싶으면 x값이 커지게 하면 됨 (오른쪽으로 이동)
- 기울기 값이 크다
  - 가파르다는 것을 의미
  - x의 위치가 최소값/최대값에 해당되는 x좌표로부터 멀리 떨어져있음
  - 기울기가 크면 크게 이동시키고 작으면 조금 이동 시킴(작을 수록 해에 가까워지니까)

경사 하강법 유도
- 사진

경사 하강법의 step size
- step size가 큰 경우
  - 한 번 이동하는 거리가 커지므로 빠르게 수렴할 수 있다는 장점이 있음
  - 하지만, step size를 너무 크게 설정해버리면 최소값을 계산하도록 수렴하지 못하고
   함수 값이 계속 커지는 방향으로 최적화가 진행될 수 있음
- step size가 너무 작은 경우
  - 발산하지는 않을 수 있지만 최적의 x를 구하는데 소요되는 시간이 오래 걸림

Local minima
- 극소값, 지역적 최소값
- 일반적인 상황에서 최적의 해가 아닌 지역적으로 낮은 값을 갖는 극소값의 문제에
   빠질 수 있음
