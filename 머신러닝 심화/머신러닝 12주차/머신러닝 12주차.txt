스마트 팩토리
- 공정 전체 과정을 디지털화하고 자동화하여 유기적으로 동작하는 지능형 공장
- 구성: AI, 빅데이터, IoT, 클라우드
- 목표: 생산 효율 향상, 불량률 최소화, 에너지 절감, 실시간 의사 결정
- 기획 설계
  - 가상공간에서 제품 제작 전 시뮬레이션
  - 기간 단축, 맞춤형 제품 개발
- 생산
  - 설비, 자제, 시스템 간 실시간 정보교환
  - 다품종 대량생산, 에너지 실비효율 제고
- 유통 판매
  - 생산 현황에 맞춘 실시간 자동 수발주
  - 재고비용 감소, 품질, 물류 등 전 분야 협력

AI의 역할
- 데이터 기반 지능형 제어의 핵심 요소
- AI가 제공하는 3가지 주요 가치
  - 예측 ( Prediction )
  - 최적화 ( Optimization )
  - 자동화 ( Automation )
- 주요기술
  - 머신러닝, 딥러닝, 강화학습
  - 컴퓨터 비전, 시계열 이상 탐지, 디지털 트윈

AI 적용 분야
- 품질 검사: 비전 AI로 결함 자동 판별
- 예지 보전: 센서 데이터로 고장 예측
- 공정 제어: 강화학습 기반 최적화 제어
- 생산 스케줄링: AI로 일정, 자원 최적화
- 에너지 관리: 소비 패턴 분석 및 절감
- 로봇 협업: AI 로봇의 자율 판단 및 작업 지원

품질 검사
- 이미지, 영상 데이터 분석해 제품의 결함, 표면 불량, 조립 이상 등을 자동으로 판별
- 활용 기술
  - CNN 기반 이미지 분류/탐지
  - Vision Transformer, YOLO, Faster R-CNN 등
- 적용 예:
  - 용접부, PCB, 반도체, 자동차 부품 등 비전 검사 자동화
  - FLIR(열화상) + AI 결합으로 온도 이상 감지 및 불량 예측

설비 이상 예지
- 센서 데이터 분석해 설비의 고장 발생 가능성을 사전에 예측 -> 정비 시점 최적화
- 활용 기술
  - 시계열 이상 탐지(LSTM, Autoencoder, Transformer 기반 모델)
  - Vibration, Acoustic, IMU 센서 등에서 수집된 데이터 분석
- 적용 예
  - 모터, 펌프, 베어링 진동 패턴 분석
  - 레이저 용접, 절삭, 주조 공정 등에서 공정 이상 조기 탐지

공정 최적화 및 제어
- 공정 데이터를 기반으로 온도, 속도, 압력 등의 제어 변수를 자동 조정해 생산 효율 향상
- 활용 기술
  - 강화학습 기반 제어 정책 학습
  - 공정 시뮬레이터 + AI 모델 조합(Digital Twin 활용)
- 적용 예
  - 제강/화학/반도체 공정의 PID 제어 보완
  - 레이저 용접, 주조 온도 제어의 AI 피드백 제어

생산 스케쥴링 및 물류 최적화
- 생산 일정, 자재 흐름, 로봇 경로 등을 AI로 최적화하여 낭비 최소화
- 활용 기술
  - 강화학습 기반 경로/자재 흐름 최적화
  - 유전 알고리즘, Q-learning
- 적용 예
  - AGV(무인 운반차) 경로 계획
  - 다품종 소량 생산에서 작업 순서 최적화

에너지 관리 및 설비 효율 향상
- 에너지 사용 데이터를 분석해 설비별 비효율적인 운전 패턴 감지 및 개선
- 활용 기술
  - 회귀 모델 기반 예측(Random Forest, XGBoost 등)
  - 딥러닝 기반 에너지 소비 패턴 모델링
- 적용 예
  - HVAC 시스템 최적 제어
  - 열처리로, 압축기, 냉각 설비 등에서 에너지 절감 제안

디지털 트윈 기반 시뮬레이션
- 실제 설비, 공정을 가상 모델로 재현해 AI 모델 학습 및 제어 실험에 활용
- 활용 기술
  - 3D 모델링 + 센서 데이터 피드백
  - 시뮬레이션 결과를 이용한 AI 예측모델 학습
- 적용 예
  - 로봇 팔의 궤적 최적화, 라인 밸런싱 시뮬레이션
  - 용접/가공 공정의 온도 분포 및 응력 예측

실시간 데이터 분석 및 의사결정 지원
- IoT 게이트웨이를 통해 수집된 데이터를 실시간으로 분석해 현장 의사결정 자동화
- 활용 기술
  - Edge AI(엣지 디바이스에서 추론 수행)
  - Stream Analytics, CEP(Complex Event Processing)
- 적용 예
  - 생산라인의 불량률 급상승 시 자동 경보 및 라인 정지
  - 온도/진동 이상 시 즉시 제어 신호 피드백

로봇 제어 및 협업
- AI가 로봇의 동작을 학습하거나, 사람과 로봇 간 협업을 효율화함
- 활용 기술
  - 강화학습 기반 동적 제어
  - 컴퓨터 비전 + 행동 인식
- 적용 예
  - 협동로봇의 안전한 작업 보조
  - AI가 작업자 동작을 인식해 공정 속도 조절

센서
- 물리적, 화학적 변화를 디지털 데이터로 변환하는 장치
- 모든 데이터는 센서에서 시작
- 설비, 환경, 제품 상태를 실시간 수집
- 주요 센서 예시
  - 온도, 압력, 진동, 위치, IMU, 비전, 열화상 센서 등
  - IoT, AI, 클라우드와 결합해 스마트 공정 구현

열화상 카메라
- 가시광선 대신 적외선을 감지해 물체의 온도 분포를 영상 형태로 표현하는 장치
- 사람의 눈으로 보이지 않는 온도 차이를 시각화 가능

열화상 카메라 동작 원리
- 적외선 방출(열복사 원리)
  - 모든 물체는 절대온도 0K(-273C) 이상이면 적외선을 방출
- 적외선 검출
  - 렌즈가 적외선을 모아 열 센서에 전달
- 전기 신호 변환
  - 검출된 적외선 세기를 전기 신호로 변환 후, 온도 계산 알고리즘으로 각 픽셀의
    온도 추정
- 열영상 생성
  - 온도 차이를 색상으로 변환해 Thermal Image 생성 (예: 파란색 =저온, 빨간색=고온)
- 장점
  - 비접촉 측정: 고온,위험 환경에서도 안전하게 측정
  - 넓은 영역 동시 분석: 다수의 온도 분포를 실시간 파악
  - 고속 반응: 공정 실시간 모니터링에 적합

열화상 카메라의 적용
- 설비 진단
  - 모터, 베어링, 배선 등의 발열 이상 탐지
  - 예지보전
- 용접/가공 공정
  - 온도 분포 분석 -> 퓸질 균일화
  - 레이저 플라즈마 용접 품질 관리
- 전력/배전반 모니터링
  - 과열 부품 탐지
  - 안전 관리 및 사고 예방
- 전자제품 제조
  - PCB 온도 모니터링
  - 열적 결함 조기 검출
- 로봇 비전 결합
  - 비접촉 품질 검사
  - 자동화 검사 시스템

열화상 카메라 AI와 결합한 고도화 방향
- AI 기반 이상 탐지 모델로 정상/비정상 온도 패턴 자동 분류
- 딥러닝 열영상 분석을 통한 공정 품질 예측
- IoT 연계로 실시간 원격 모니터링 및 클라우드 데이터 분석

열화상 카메라 효과
- 생산성 향상 -> 불량률 감소, 자동화 검사 기능
- 비용 절감 -> 고장 예방으로 유지보수 비용 절감
- 안전성 강화 -> 고온, 위험 환경의 무인 모니터링 가능

열화상 카메라 사례 - 고장 진단 및 화재 예방
- 열화상 카메라 역할
  - 비접촉식으로 설비 표면의 온도 분포 실시간 측정
  - 전류, 마찰, 절연 불량, 과열 등 잠재적 이상 징후를 조기에 탐지
- 고장 진단 활용
  - 모터,베어링 과열 / 전력 케이블 접속 불량 / 제어반 발열 이상 감지
  - 정상 장비와의 온도 패턴 비교로 고장 위치 및 원인 식별
  - 진동/전류 센서 등과 연동 시 다중 진단 시스템 구성
  - 정비 주기 최적화 -> 다운타임 감소, 유지비 절감
- 화재 예방
  - 분전반, 배전반, 컨베이어 등 고온 구역 상시 감시
  - 온도 임계치 초과시 자동 알람 또는 시스템 차단 연동
  - 인체 접근 어려운 구역(탱크, 고온로 등) 에서도 안전하게 모니터링
  - 공장 내 24시간 무인 감시 시스템 구축 가능
- AI + 열화상 융합
  - 열화상 데이터 기반 이상 패턴 학습 -> 자동 진단 모델 구축
  - 정상/비정상 상태 분류, 고장 예측, 화재 위험 예측
  - 생산 라인 품질 데이터와 연계해 통합 스마트 유지보수 체계 완성

열화상 카메라 사례 - 전기차 진단
- 용접 품질 검사
  - 배터리 셀을 팩으로 조립하는 과정에서 용접 불량은 출력 저하, 수명 단축 유발
  - 기존 파괴검사는 셀 손상 위험 존재
  - 열화상 카메라로 용접부 온도차를 감지해 비파괴, 비접촉 검사 가능
  - 불량 솔기: 표면 온도 높음/형상 불균일
- 셀 누출 감지
  - 미세 누출은 육안 식별 어려움 및 인체 위해
  - 질량분석기보다 열화상 방식이 빠르고 효율적
  - 온도차 패턴 분석으로 누출 부위 즉시 탐지
- 불규칙한 온도 분포 감시
  - 결합 셀은 미세한 온도 상승으로 확인 가능
  - 열전대 한계(국소 측정) -> 열화상 카메라는 넓은 영역 동시 모니터링 가능
  - 온도차 미확인 시 화재 위험 증가
- 충/방전 단계 검사
  - 충,방전 중 표면 온도는 주변보다 약 5~6도 상승
  - 핫스팟 위치 파악 및 내부 열 거동 추정 가능
  - 실시간 모니터링으로 잠재 결함 조기 감지
- 전기차 완성차 점검
  - 배터리 모터 인버터의 열 거동 관찰
  - 주행 중 온도 모니터링으로 화재 예방 및 안정성 확보
  - 배터리 제조~운용 단계까지 통합 진단 솔루션 제공

열화상 카메라 사례 - 건물진단
- DarkWave Thermo(이탈리아 브레시아)의 건물 외장재 탈락 조사
  - 대형 건물 점검 시 많은 인력 대신 열화상 카메라를 활용해 타일과 벽 외장재 탈락 조사
  - 공인 외관 분석 전문가가 진단 및 소송 지원용 감정에 활용
- 기존 문제점
  - 외관 정비 시 많은 인력, 리프트, 비계 설치 등 고비용 필요
  - 날씨, 노후화, 시공 불량 등으로 코팅 재료(석고, 타일, 대리석 등) 탈락 위험
  - 탈락 시 안전사고 및 구조적 손상 우려
- 열화상 카메라의 역할
  - 비접촉, 비파괴 방식으로 외관의 탈락 부위 탐지
  - 열 특성 차이를 이용해 접착 불량 구역을 시각적으로 식별
  - 적절한 렌즈 선택과 촬영 조건(일광, 각도 등)이 중요
- 성과 및 장점
  - 시간, 비용 절감, 리프팅 장비 불필요
  - 신뢰도 높은 진단 결과로 안전 확보
  - 도시 환경에서 가장 유연하고 효율적인 점검 방법으로 평가

열화상 카메라 사례 - 가스 누출
- 열화상 카메라를 이용한 가스 누출 검지
  - 산업 플랜트, 화학 공장, 에너지 설비에서는 가연성-유해 가스 누출이 심각한 사고로
    이어질 수 있음
  - 적외선 영역에서 가스의 복사 흡수 특성을 이용해 육안으로 보이지 않는 가스 영상으로
   시각화
- 원리
  - 각 가스는 특정 적외선 파장을 흡수함
  - 냉각형 IR 검출기는 해당 파장을 선택적으로 감지
  - 누출된 가스는 주변 공기 대비 온도, 복사 에너지 차이로 검출됨
- 장점
  - 비접촉식, 실시간 탐지 -> 접근 어려운 구역에서도 안전한 검사
  - 비파괴 검사(NDT) -> 가동 중인 설비에도 사용 가능
  - AI 연동 시 누출 패턴 자동 인식 및 위험 등급 판단 가능
  - 영상 기록을 통해 유지보수, 법적 근거 확보 용이
- 주의 및 한계
  - 각 가스의 흡수 파장대에 맞는 전용 카메라 필요
  - 풍속, 온도, 배경 복사율 등 환경조건에 따라 검출 성능 영향
  - 정기 보정 및 숙련된 운용자 필요

음향 방출 센서
- 원리
  - 재료 내부의 균열, 마찰, 누설 등에서 발생하는 탄성파(고주파)를 감지
  - 센서가 구조물 표면에 부착되어 응력 변화나 손상 발생 시 발생하는 파형을 전기 신호로
    변환
  - 일반적으로 100kHz ~ 1MHz 대역의 초음파를 사용
- 중요특징
  - 비파괴 검사 방식
  - 미세 균열, 피로 손상, 누설 등 초기 이상 조기 검출 가능
  - 단일 센서 또는 배열 형태로 배치해 위치 추적 수행
- 적용 분야
  - 압력 용기, 배관, 용접부, 복합재 구조물의 균열 및 누설 진단
  - 풍력, 원자력, 항공 부품 등 고신뢰성 구조물 모니터링
  - 스마트 팩토리 설비의 예지보전

플라즈마 센서
- 고온 공정 중 발생하는 플라즈마 방출 신호(빛, 전자, 이온, 전자기파 등)를 감지하는 센서
- 플라즈마 방출은 공정의 안정도, 에너지 전달, 용입 깊이 등과 직접적으로 연관
- 실시간 비접촉 방식으로 공정 상태 및 불량 요인 감시 가능
- 작동 원리
  - 용융 금속 표면에서 발생하는 플라즈마는 전자기 복사 형태로 빛을 방출
  - 센서는 이 빛의 강도, 주파수 스펙트럼, 시간 변동성을 분석
  - 플라즈마 세기 -> 공정 에너지 안정성, 방출 스펙트럼 -> 재료 반응 및 결합 여부로 해석
  - AI 모델과 결합 시 실시간 품질 판별 및 이상 감지 가능
- 특징
  - 검출방식: 광학식
  - 측정 대상: 플라즈마 방출광, 전자기 신호
  - 측정 방식: 비접촉, 실시간
  - 장점: 공정 중단 없이 모니터링 가능, 빠른 이상 감지
  - 결합 기술: 카메라, 열화상, AE 센서, AI 분석 시스템

플라즈마 센서 사례 - 용접 불량 검출
- 레이저 용접 공정의 실시간 품질 관리
  - LWM은 레이저 용접 공정을 24시간 실시간으로 모니터링하는 시스템으로, 열전도
    용접, 키홀 용접 등 전 레이저 공정의 품질 및 생산성 데이터를 기록, 분석
  - 고성능, 마이크로 용접 모두 지원하며, 공차,오염,마모 등 품질 변동 요인 감지
- 감지 가능한 주요 결함
  - 출력, 초점 불량 -> 비균일 용접선 발생
  - 부품 간 간격 과다 -> 융합 부족(불완전 접합)
  - 표면 오염(오일, 먼지, 녹) -> 용접 강도 저하
  - 스패터, 기공 발생 -> 용접 품질 저하 및 표면 결합

플라즈마 센서 사례 - 불량 원인 판단
- 용접 결함의 원인을 실시간으로 규명해 품질 저하, 재작업, 라인 정지를 사전 예방
- 데이터 기반 피드백 제어 통해 공정 안정성 확보
- 용입 불량
  - 레이저 출력 부족, 초점 오차, 부품 간 간격 과다
  - 광학, 열 신호 분석(LWM 센서)
- 기공
  - 가스 혼입, 과도한 스패터 발생, 냉각 불균일
  - 플라즈마/열 방출 신호 이상
- 표면 스패터
  - 오염, 레이저 출력 과다, 초점 위치 불안정
  - 고속 광센서로 순간 신호 검출
- 크랙
  - 과도한 열응력, 냉각속도 불균일, 소재 결함
  - 온도 채널 및 음향 신호 분석
- 융합 부족/오버랩
  - 용접 속도 과도, 초점 높이 불일치
  - 실시간 공정 데이터 비교 분석
