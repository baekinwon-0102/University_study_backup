활성화 함수 (시험문제 무조건 나옴)
- 인공신경망에서 각 뉴런이 입력을 받아 출력 계산하는 함수

활성화 함수 사용 이유
- 출력값을 0~1 사이 값으로 반환해야 하는 경우 사용
- 비선형 위해 사용
- 선형함수인 [f(x)=W * x] 식이 있다고 가정하면
  은닉층이 2개 사용 시 식은 [f(f(f(x))) = W*W*W*x=kx]로 단순하게 변형됨
- 은닉층 여러개 사용해도 동일한 결과
- 즉, 선형함수로는 은닉층을 여러 개 추가해도 은닉층을 1개 추가한 것과 차이가 없어
   정확한 결과를 위해선 비선형 함수, 즉 활성화 함수가 필요

시그모이드(Sigmoid)
- x값의 변화에 따라 0에서 1까지의 값을 출력하는 S자형 함수
- 로지스틱 함수라고도 부름
- 1/1+e^-x

하이퍼볼릭 탄젠트(Hyperbolic Tangent)
- 시그모이드와 유사
- 하지만 -1~1의 값을 가지면서 데이터의 평균이 0이라는 점이 다름

렐루(ReLU)
- x가 음의 값을 가지면 0을 출력하고, 양의 값을 가지면 x를 그대로 출력
- 함수 형태도 max(0,x)로 계산이 간단하여 학습 속도가 매우 빠름

리키렐루(LeakyReLU)
- 렐루 함수와 유사
- 차이점은 가중치 곱의 합이 0보다 작을 때 값도 고려함
- 이 함수는 렐루 함수의 '죽은 렐루'현상을 보완

※ 레이어가 적다면 시그모이드, 하이퍼볼릭 탄젠트를 대부분 사용/레이어가 많으면
  렐루가 좋음 -> 시그모이드와 하이퍼볼릭 탄젠트는 레이어가 많으면 기울기 소실 문제가
   있음

소프트맥스
- 입력받은 값이 0~1 사이의 값으로 출력되도록 정규화하여 출력의 총 합이 1이 되는 특성
  을 갖는 함수
- 딥러닝에서 출력 노드의 활성화 함수로 많이 사용

※ 히든 레이어는 입력 레이어 개수의 1.5~2배 정도가 적절함
※ 문제의 분포에 따라 입력값(feature)를 x*y의 값을 쓴다던지 차원을 높여서 사용하면
   더 좋은 성능을 낼 때가 있음
