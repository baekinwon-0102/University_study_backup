강화학습의 구조
- 시행 착오를 통해 기계를 학습하는 것
- 환경과 상호작용 통해 보상 획득하고 이를 기반으로 행동 결정
- 걸음마, 자전거 배우기와 유사한 방식

강화 학습의 요소 (★시험 무조건 나옴★)
- 행위자: 행동하는 주체
- 환경: 주변의 모든 것
- 상태: 행위자가 인식하는 환경
- 행동: 행위자의 행위
- 보상: 행동에 따른 결과

강화 학습 적용 분야
- 게임 AI
- 지능 로봇

게임 분야에서의 강화학습
- 알파고의 경우 순수 강화학습 만으로 기존 버전 성능 모두 넘어섬
- 지도 학습과 혼용하는 경우 기존 바둑 이론 기반으로 생각하고, 알파고 제로는
   바둑 이론에서 독립된 창의적 방식으로 동작

OpenAI Gym Library
- python 기반 강화학습 라이브러리
- 강화학습 기초와 구조 파악 위한 튜토리얼 제공

Unity 강화학습 엔진
- 간단한 Python API로 강화 학습 통한 인공지능 구현 가능
- 시각적 콘테츠와 현실적 물리로 복잡한 행동
- 대규모 병렬 교육 시스템 실행

CartPole 문제
- 상태는 박스의 Position, Velocity 등이 상태를 나타냄

쿠키런 강화학습 방식(★시험에 무조건 나옴★)
- 행위자: 달리는 쿠키
- 상태: 행위자 위치, 장애물과 쿠키의 위치
- 보상: 점수
- 환경: 환경: 게임 속 모든 것
- 행동: 가만히, 슬라이드, 점프

강화학습 과정
- 실패한 행동에 대해 결과를 0으로 만드는 방식으로 정답지 수정
  1. 상태 인식
  2. 행동 결정
  3. 보상확인
  4. 정답지 조정
  5. 연결 세기 조절
  6. 새로운 기계

학습률(시험 무조건 나옴)
- 뉴런을 연결하는 가중치 값을 한 번 수정할 때 얼마만큼 수정할지를 정하는 값
