인터페이스
- 클래스와 클래스 사이의 상호 작용의 규격을 나타낸 것
- 멤버변수 올 수 없음(단 상수는 가능)
- 아무것도 없는 껍데기 메서드만 존재
- 클래스라고 표현하지 않음
- abstract 붙일 필요는 없음
- 자기 자신 객체화 불가
- 인터페이스 상속은 implements ( extends 아님 )
- 인터페이스로 상속받으면 반드시 인터페이스의 메서드 오버라이딩해야 됨
- 유일하게 자바에서 다중 상속이 가능함 -> implements로 2개 이상 받고 extends까지도 가능
- default 메서드는 가능(public default void -----)
- default 메서드를 상속받은 클래스에선 사용 가능하지만 상속받지 않은 곳에선 메서드
  사용 불가
- 인터페이스가 인터페이스를 상속할 수 있음 <--- 시험 무조건 나옴
  - 인터페이스가 인터페이스 상속할 땐 extends <--- 시험 무조건 나옴 헷갈리지 마셈

JFrame
- 화면디자인 클래스
- javax.swing.JFrame
- extends JFrame으로 불러옴
- 모듈 있으면 안 됨
- 대표적인 레이아웃 3가지
  - FlowLayout(순서대로)
  - GridLayout(행, 열)
  - BorderLayout(동서남북, 중간)
- textarea (텍스트 창)
- textfiled (텍스트 입력)
