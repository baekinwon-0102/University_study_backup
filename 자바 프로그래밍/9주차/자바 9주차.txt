접근 지정자
- 자바의 접근 지정자
  - private, protected, public, default(접근지정자 생략)

접근 지정자 목적
- 클래스나 일부 멤버 공개해 다른 클래스에서 접근하도록 허용
- 객체 지향 언어의 캡슐화 정책은 멤버를 보호하는 것
  - 접근 지정은 캡슐화에 묶인 보호를 일부 해제할 목적

접근 지정자에 따른 클래스나 멤버 공개 범위
- private < default < protected < public

멤버변수 접근 함수
- setter, getter
- 이클립스 Source에서 generate setter, getter 누르면 자동 생성

클래스 접근지정
- 다른 클래스에서 사용하도록 허용할 지 지정
- public 클래스: 다른 모든 클래스에게 접근 허용
- 디폴트 클래스(접근지정자 생략): package-private라고도 함, 같은 패키지 클래스만 접근 허용

상속 명령어
- extends

static ( 기말고사 나옴 )
- 공유멤버변수
- 객체들 사이에서 공유하고 싶은 멤버변수 지정할 때 쓰는 예약어
- 클래스당 하나만 생성하여 클래스의 멤버변수
- this를 사용할 수 없다
- static 멤버변수를 set/get 메서드를 정의할 때 static 메서드

정적 멤버
- 정적멤버(static member)는 모든 객체를 통틀어서 하나만 생성되고 
  모든 객체가 이것을 공유

정적 변수
- 모든 객체에 공통인 변수, 하나의 클래스에 하나만 존재

ex) static 안 붙이면 변동금리, static 붙이면 고정금리
