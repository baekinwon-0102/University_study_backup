## 정형 데이터 마이닝

앙상블
- 여러 가지 같은 종류 또는 서로 다른 모형들 예측/분류 결과 종합해 최종적 의사결정에
  활용하는 기법
- 통일, 조화등을 나타내는 용어
- 더 높은 신뢰성 확보
  - 다양한 모형의 예측 결과를 결합함으로써 단일 모형으로 분석했을 때 보다 높은 신뢰성
    있음
- 정확도 상승
  - 이상값에 대한 대응력 높아지고 전체 분산을 감소
  - 모형 간의 상호 연관성이 높을 수록 정확도는 떨어짐
- 원인 분석에 부적합
  - 단일 모형이 아니기에 모형의 투명성이 떨어지게 되어 정확한 현상의 원인 분석에는 
    부적합

배깅
- 훈련 데이터에서 다수의 부트 스트랩 자료 생성하고 각 자료 모델링 후 결합해 최종 예측
  모형을 만드는 알고리즘
- 부트스트랩은 주어진 자료에서 같은 크기 표본을 랜덤 복원 추출로 뽑은 자료 의미
- 부트 스트랩 데이터 추출
  - 분석 데이터로부터 n개의 부투스트랩 데이터 추출(동일 크기)
- 단일 분류기 생성
  - 부트스트랩 데이터에 적합한 모델(예: 의사결정나무)을 적용해 n개 단일 분류기 생성
- 최종 모델 결정
  - n개의 단일 분류기 중 다수결 또는 평균을 통해 최종 모델 결정
  - 범주형 변수: 다수결, 연속형 변수: 평균

부스팅
- 여러 개의 모형을 구축한다는 점에서 배깅과 유사하지만 배깅은 각 분류기가 독립적인데
   비해 부스팅은 독립적이지 않음
- 부스팅은 이전 모델 구축한 뒤 다음 모델 구축할 때 이전 분류기에 의해 잘못 분류된
  데이터에 더 큰 가중치를 주어 부스트랩을 구성
- 예측력이 약한 모형들을 결합해 나감으로써 점차적으로 강한 분류기를 만들어 나가는
  과정
- 부스트랩을 재구성하는 과정에서 잘못 분류된 데이터에 더 큰 가중치 주어 표본을 
  추출하기 때문에 훈련 오차를 빠르게 줄여 예측 성능은 배깅보다 뛰어나다고 할 수 있음
- 동일 가중치 분류기 생성
  - 같은 가중치의 분석 데이터로부터 분류기 생성
- 가중치 변경을 통한 분류기 생성
  - 이전 분석 데이터의 분류 결과에 따라 가중치 변경을 통해 분류기 생성
- 최종 분류기 결정
  - 목표하는 정확성이 나올 때까지 N회 반복 후 최종 분류기 결정

랜덤 포레스트
- 서로 상관성이 없는 나무들로 이루어진 숲을 의미, 배깅과 유사하나 배깅에 더 많은
  무작위성 주는 분석기법
- 많은 무작위성으로 생성된 서로 다른 여러 개 트리로 구성되어 있기 때문에 포레스트라
  명명되었으며, 여러 개의 약한 트리들의 선형 결합으로 최종 결과 얻는 모델
- 분류의 경우 다수결로 최종 결과 구하며 회귀의 경우 평균 or 중앙값 구해 선택
- 큰 분산 가지고 있다는 의사결정나무의 단점 보완 위해 부스트랩 데이터에서 표본 추출
  과정을 거쳐 분산을 감소시키고 모든 분류기들이 높은 비상관성을 갖기 때문에 일반화
  의 성능 향상 가능
- 랜덤 포레스트 특징
  - 분류기 여러 개 쓸수록 성능 좋아짐
  - 트리 개수 많을 수록 과대 적합 문제 피할 수 있음
  - 여러 개의 의사결정나무가 모여 랜덤 포레스트 구조가 됨

스태킹
- 일반적 앙상블 기법은 각 분류기 간의 결과 활용해 보팅방식에 의해 최종결과를 선정하는
  방식이지만, 스태킹은 보팅방식이 아닌 여러 분류기 간 결과 다시 훈련용 데이터로 사용해
  최종 모형 구축
- 여러 개의 분류기는 서로 다른 알고리즘으로 작성될 수 있으며 여러 기초 모델에서 예측된
  결과로부터 구축된 최종 모형을 메타모델이라 함

모형 평가
- 과대 적합에 대해 신뢰할 만한 추정값 구하기 위해 훈련용, 평가용 데이터 나누어 이용
- 빅데이터 분석 모형 검증위한 대표적 평가방법은 홀드 아웃 방법, K-Fold Cross Validation,
  LOOCV, LpOCV, 부트스트랩 등이 있음

홀드 아웃 방법
- 전체 데이터를 비복원 추출 방법 이용해 랜덤하게 훈련용, 평가용 데이터로 나눠 검증
- 훈련용 데이터로 분석 모형 구축, 평가용 데이터 이용해 분석 모형 평가
- 계산량이 많지 않아 모형 쉽게 평가할 수 있으나 전체 데이터에서 평가용 데이터만큼
  학습에 사용할 수 없으므로 데이터 손실 발생
- 데이터 어떻게 나누느냐에 따라 결과 많이 달라질 수 있음
- 데이터 양이 충분한 경우 훈련용, 검증용, 평가용 데이터로 나누기도 함
- 훈련용 데이터: 분석 모델 만들기 위해 사용하는 데이터 세트
- 검증용 데이터: 훈련용 데이터로 만든 모델이 잘 예측하는지 성능 평가 위한 데이터 세트
- 평가용 데이터: 검증용 데이터로 최종모델 선택, 그 성능 테스트 위해 사용되는 
                     데이터 세트

K-Fold Cross Validation
- 데이터 집합을 무작위로 동일 크기를 갖는 k개의 부분 집합으로 나누고, 그 중 1개 집합을
  평가용 데이터, 나머지(K-1)개 집합을 훈련용 데이터로 선정해 평가
- 모든 데이터를 훈련과 평가에 사용할 수 있으나 K값 증가시 수행시간, 계산량 많아짐
- k번 반복 수행해, 결과 K번 성능에 대한 다수결 또는 평균으로 분석
- 동등 분할
  - 전체 데이터를 K개 같은 크기의 부분 집합으로 랜덤하게 나눔
- 훈련용/평가용 데이터 구성
  - (K-1)개 부분 집합들은 훈련용 데이터, 나머지 1개 부분 집합 평가용 데이터로 하는
    K개의 실험 데이터 구성
- 분류기 학습
  - 각 실험 데이터마다 훈련용 데이터로 분류기 학습시키고 평가용 데이터로 분류기 성능
    평가
- 분류기 성능 확인
  - 실험 결과 K개를 종합해 해당 분류기의 최종 성능 구함

LOOCV
- 전체 데이터 N개 중 1개 샘플만 평가용 데이터에 사용하고 나머지 (N-1)개는 훈련용
  데이터로 사용하는 과정을 N번 반복하는 교차 검증 기법
- K-Fold와 같은 방법 사용하며 이때 K는 전체 데이터 N과 같음(K=N)
- 가능한 많은 데이터 훈련에 사용할 수 있지만 수행 시간, 계산량 많음
- 작은 크기 데이터에 사용하기 좋음

LpOCV
- LOOCV에서 1개의 샘플이 아닌 p개의 샘플을 평가에 사용하는 교차 검증 기법
- 계산 시간에 대한 부담 매우 큼

부트스트랩
- 주어진 자료에서 단순 랜덤 복원 추출 방법 활용해 같은 크기 표본을 여러 개 생성하는
  샘플링 방법
- 무작위 복원 추출 방법으로 전체 데이터에서 중복 허용해 표본 크기만큼 샘플 추출하고
  이를 훈련용 데이터로 하는 방법으로 전체 데이터 샘플이 N개이고 부트 스트랩으로 n개의
  샘플을 추출하는 경우 특정 샘플이 훈련용 데이터에 포함될 확률 63.2%
- 부트스트랩을 통해 1000번 샘플 추출해도 샘플에 한 번도 선택되지 않은 원 데이터 발생
  가능한데 전체 샘플의 약 36.8%가 이에 해당
- 한 번도 포함되지 않은 OOB데이터는 검증에 사용

분류 모형의 평가지표
- 혼동 행렬을 이용한 평가지표와 ROC곡선의 AUC를 많이 사용

혼동행렬
- 분석 모델에서 구한 분류의 예측 범주와 데이터 실제 분류 범주를 교차 표 형태로 
  정리한 행렬
- 정확도
  - 실제 분류 점주 정확하게 예측한 비율
  - 전체 예측에서 참 긍정(TP)과 참 부정(TN)이 차지하는 비율
- 오차 비율
  - 실제 분류 범주를 잘못 분류한 비율
- 재현율 or 민감도
  - 실제로 긍정인 범주 중 긍정으로 올바르게 예측한 비율
  - Hit Rate로도 지칭(참 긍정률)
- 특이도
  - 실제로 부정인 범주 중 부정으로 올바르게 예측한 비율
- 거짓 긍정률
  - 실제로 부정인 범주 중 긍정으로 잘못 예측한 비율
- 정밀도
  - 긍정으로 예측한 비율 중 실제로 긍정인 비율
- F1 지표
  - 정밀도와 민감도 하나로 합한 성능평가 지표
  - 0~1 범위 가짐
  - 정밀도와 민감도 양쪽이 모두 클 때 큰 값 가짐
- 카파 통계량
  - 두 관찰자가 측정한 범주 값에 대한 일치도 측정
  - 0~1의 값을 가지며 1에 가까울수록 모델 예측값과 실제값이 정확히 일치하며 0에 가까
   울수록 모델 예측값과 실제값이 불일치
  - K: 카파계수, Pr(a): 예측이 일치할 확률, Pr(e): 예측이 우연히 일치할 확률

ROC 곡선
- 가로축을 혼동 행렬의 거짓 긍정률로 두고 세로축을 참 긍정률로 두어 이진 분류 모형의
  성능 평가위해 사용
- 그래프가 왼쪽 꼭대기에 가깝게 그려질수록 분류 성능 우수
- 거짓 긍정률과 참 긍정률은 어느 정도 비례 관계
- AUC는 진단의 정확도 측정 시 사용하는 것으로 ROC 곡선 아래 면적을 모형의 평가지표로
  삼음
- AUC 값은 항상 0.5~1의 값을 가지며 1에 가까울 수록 좋은 모형

이익도표
- 분류 모형 성능 평가 위해 사용되는 도표 형태 그림
- 이익은 목표 범주에 속하는 개체들이 임의로 나눈 등급별로 얼마나 분포하고 있는지
   나타내는 값
- 해당 등급 따라 계산된 이익 값 누적으로 연결한 도표가 이익 도표

이익 도표와 향상도 곡선
- 향상도 곡선은 랜덤 모델과 비교했을 때 해당 모델의 성과가 얼마나 향상되었는지를 구간
  별로 파악하는 그래프
- 좋은 모델일수록 큰 값에서 시작해 급격히 감소함(상위 20% 데이터가 2배 좋은 예측력)

## 군집 분석

군집분석의 개념
- 관측된 여러 개의 변수값으로부터 유사성에만 기초하여 n개의 군집으로
  집단화하여 집단의 특성을 분석하며, 다변량분석(상관분석, 회귀분석 등)을 활용하여 군집 
  에 대한 특징을 파악함
- 군집분석의 목적은 레이블이 없는 데이터 세트의 요약 정보를 추출하고, 요약 정보를 통해 
  전체 데이터 세트가 가지고있는 특징을 발견하는 것임

군집분석의 가정
- 군집 내에 속한 개체들의 특성은 동질적이고 서로 다른 군집에 속한 개체 간의 특성은 이  
  질적임
- 군집분석은 이질적인 모집단을 세분화시키는 방법임
- 군집 내의 응집도는 최대화하고 군집 간의 분리도는 최대화함
- 군집의 개수 또는 구조와 관계없이 개체 간 거리를 기준으로 분류함
- 개별 군집의 특성은 군집에 속한 개체들의 평균값으로 나타냄

군집분석의 특징
- 군집분석은 데이터에 분류의 기준이 없는 비지도학습 방법을 사용함
- 군집분석은 신뢰성과 타당성을 점검하기 어려움
- 군집을 만든 결과가 얼마나 유용한지 따지는 군집 타당성 지표에는 군집 간 거리, 군집의  
   지름, 군집 간 분산과 군집 내 분산 등이 있음
- 군집의 품질을 정량적으로 평가하는 군집의 타당성 지표는 Dunn Index와 실루엣 지수가 
  있음
- Dunn Index
  - (군집과 군집 사이 거리 중 최소값) / (군집 내 데이터들 거리 중 최대값)
  - 분자가 클수록 군집 간 거리가 멀고 분모 값이 작을수록 군집 내 데이터가 모여 있으므
    로 좋은 군집화라고 할 수 있음 (모든 군집을 고려함)
- 실루엣 지수 (계수)
  - 군집 내의 거리와 군집 간의 거리를 기준으로 한 클러스터 안의 데이터들이 다른 클러스
    터와 비교해서 얼마나 비슷한가를 나타내어 군집 분할의 성과를 나타내는 군집 모형의 
    평가 기준
  - 군집 내의 데이터 응집도와 군집 간 분리도를 계산하여 군집 내의 데이터의 거리가 짧을
    수록 군집 간 거리가 멀수록 값이 커지는 지표 (인접한 군만을 고려)
  - 완벽한 분리일 경우 1의 값을 가지며 군집화가 잘 되었다고 판단함
 
군집분석의 유형
- 군집분석의 유형에는 계층 기반, 비계층 기반 군집분석으로 나눌 수 있음
- 계층 기반 군집분석에는 군집 간 연결법(최단, 최장, 평균, 중심, 와드연결법)이 있으며 비
  계층 기반 군집분석에 분할, 분포, 밀도, 그래프 기반 등의 분석 기법이 있음
- 비계층 기반 군집분석의 상세 기법에는 k-평균 군집, 혼합분포 군집(가우시안 혼합 모델, 
   EM 알고리즘), DBSCAN, SOM 등이 있음
- 계층적 군집 분석의 특징
  - 군집의 개수를 미리 정하지 않고 유사한 개체를 묶어 나가는 과정을 반복하여 원하는 개
    수의 군집을 형성하는 방법
  - 이상값에 민감함
  - 한번 군집이 형성되면 다른 군집으로 이동할 수 없음
  - 덴드로그램으로 표현할 수 있음
- 비계층적 군집 분석의 특징
  - 미리 군집의 개수를 지정해야 함
  - 사용자가 사전 지식 없이 그룹의 수를 정해주는 일이 많아 결과가 잘 나오지 
    않을 수 있음

계층적군집
- 계층적 군집은 유사한 개체를 군집화 하 는과정을 반복하여 군집을 형성하는 방법
- 계층적 군집을 형성하는 방법에 병합적 방법과 분할적 방법이 있음
- 병합적  방법
  - 각 데이터를 하나의 군집으로 간주하고 가까운 데이터부터 순차적으로
   병합해 나감
  - 대표적인 방법으로 몇 개의 군집으로 나눌 것인지 사전에 정할 필요 없음
- 분할적  방법
  - 전체 데이터를 하나의 군집으로 간주하고 각각의 관측치가 하나의 군집
    이 될 때까지 군집을 순차적으로 분할함

군집간의연결법
- 최단  연결법 (=단일  연결법)
  - 각 군집에서 하나씩 관측값을 뽑았을 때 거리의 최소값을
    측정하여 가장 유사성이 큰 군집으로 병합해 나감
  - 길게 늘어진 사슬 형태의 군집이 형성될 수 있고 고립된 군
    집을 찾는데 중점을 둔 방법
- 최장  연결법 (=완전  연결법)
  - 각 군집에서 하나씩 관측값을 뽑았을 때 거리의 최대값을
    측정하여 가장 유사성이 큰 군집으로 병합해 나감
  - 내부 응집성에 중점을 둔 방법으로 둥근 형태의 군집이 형
    성됨
- 중심연결법
  - 두 군집의 중심 간의 거리를 측정하여 가장 유사성이 큰 군
   집으로 병합해 나가는 방법으로 두 군집이 결합할 때 새로
   운 군집의 평균은 가중평균을 통해 구함
  - 평균연결법보다 계산량이 적고 모든 관측치 사이의 거리를
    측정할 필요가 없음
- 평균 연결법
  - 모든 항목에 대한 거리 평균을 구하면서 가장 유사
    성이 큰 군집을 병합해 나가는 방법
  - 계산량이 불필요하게 많아질 수 있음
  - 최단연결법과 최장연결법보다 이상치에 덜 민감함
- 와드  연결법
  - 군집 내의 편차 제곱 합에 기초하여 군집을 수행하
    는 방법으로 편차 제곱합의 증가량이 최소가 되는
    방향으로 군집을 형성해 나가는 방법
  - 크기가 비슷한 군집끼리 병합하는 경향이 있음

  필요함
- 거리는 값이 작을수록 관측치가 유사함
- 연속형 변수 거리에는 유클리디안거리, 맨하탄거리, 민코프스키거리, 표준화거리, 마할라
  노비스거리등이있음

계층적 군집모형의 특징
- 계층적 군집방법은 군집을 형성하는 매단계에서 지역적 최적화를 수행하는 방법을 사용하
  므로 그 결과가 전역적인 최적해라고는 볼 수 없음
- 병합적 방법에서 한 번 군집이 형성되면 군집에 속한 개체는 다른 군집으로 이동할수 없음
- 중심연결법, 와드연결법등에서 군집의 크기에 가중을 두어 병합을 시도하므로 크기가 큰
  군집과의 병합 이유도 될 수도 있음

비계층적군집
- 계층적으로 군집을 형성하지 않고 구하고자 하는 군집의 수를 사전에 정의해 정해진 군집
  의 수만큼 형성하는 방법
- 비계층적 군집분석은 계층적 군집분석과 다르게 데이터간 거리행렬을 사용하여 분석을 
  수행하지 않음
- 또한 원하는 군집의수(k)의 초기값을 설정하고 분석을 수행하게 됨
- 대표적인 방법으로 k-means(k-평균) 군집이 있음

K-평균군집의개념
- K-평균군집은 주어진 데이터를 k개군집으로 묶는 알고리즘으로 k개만큼 군집수를 초기값
  으로 지정하고, 각 개체를 가까운 초기값에 할당하여 군집을 형성하고 각 군집의 평균을 
  재계산하여 초기값을 갱신하는 과정을 반복하여 k개의 최종군집을 형성함
- K-평균군집에서 군집의수(k)는 초매개변수(하이퍼파라미터)로서 분석자가 미리 정해주어
  야함

K-평균군집의절차
- k개  객체  선택
  - 초기 군집 중심으로 k개의 객체를 임의로 선택함(K=3 가정)
- 할당
  - 자료를 가장 가까운 군집 중심에 할당
  - 자료를 군집의 중심점으로부터 오차 제곱합이 최소가 되도록 각 자료를 할당하는 과정
- 중심  갱신
  - 각 군집 내의 자료들의 평균을 계산하여 군집의 중심을 갱신
  - 한 개체가 속해 있던 군집에서 다른 군집으로 이동해서 재배치가 가능
- 반복
  - 군집 중심의 변화가 거의 없을때(또는 최대 반복 수)까지 단계2와 3을 반복

K-평균군집의특징
- 알고리즘
  - 군집의 수는 분석자가 미리 정해주어야 하는 초 매개변수
  - K개의 초기 중심값은 임의로 선택될 수 있으나 데이터 중에서 무작위로 선택하는 것이    
    더 편리
  - 군집의 수를 정하기 위해 군집 수에 따른 집단 내 제곱 합의 그래프를 그려보는 방법도    
    활용
  - K-평균 군집은 군집 과정 중에 개체가 속해 있던 군집에서 다른 군집으로 이동해서 재배
    치가 가능함
- 성능
  - 초기 군집 수를 결정하기 어렵고, 초기값 선택이 최종군집 선택에 영향을 미침
  - 안정된 군집은 보장하나 최적의 군집이라는 것은 보장하지 못함
  - 알고리즘이 단순하며 빠르게 수행되며 계층적 군집보다 많은 양의 자료를 다룰 수 있음
  - 평균 등 거리 계산에 기반하므로 모든 변수가 연속적이어야 하고 잡음이나 이상값에 민
    감하는 반응하는 단점이 존재
  - 단점을 보완하는 방법으로 k-중앙값 군집을 사용하거나 이상값을 미리 제거할 수도 있음

K-평균군집의k값선정기법
- 엘보우  기법
  - X축에 클러스터의 개수(k값)를 y축에 SSE(오차제곱합)를 두었을 때 기울기가 완만한
    부분(팔꿈치 부분)에 해당하는 클러스터를 선택하는 기법
- 실루엣  기법
  - 각 군집 간의 거리가 얼마나 분리되어 있는지를 나타내는 기법
  - 실루엣 계수는 1에 가까울수록 군집 간 거리가 멀어서 최적화가 잘 되어 있고 0에 가
    까울수록 군집 간 거리가 가까워서 최적화가 잘 안되어 있음
  - 실루엣 계수는 군집 내의 데이터 응집도와 군집 간 분리도를 계산하여 군집 내의 데이
   터의 거리가 짧을수록 군집 간 거리가 멀수록 값이 커지는 지표
- 덴드로그램
  - 계층적 군집 분석의 덴드로그램 시각화를 이용하여 군집의 개수 결정

혼합 분포 군집
- 데이터가 여러 분포를 확률적으로 선형 결합한 k개 모형의 합으로 표현되는 
  모집단으로부터 나왔다는 가정하에 같은 확률분포에서 추출된 데이터들끼리 군집화 하는  
  분석기법임
- 데이터들이 몇 개의 확률 분포로 구성되어 있는지 각각의 확률분포의 모수(평균, 분산)와
  그 확률분포가 전체 데이터에서 차지하는 비중(가중치)을 찾는 것이 혼합분포군집의 
  핵심개념임
- 모수와 가중치를 추정하는 방법으로 EM 알고리즘을 사용함

혼합분포군집의특징
- 확률분포를 도입하여 군집을 수행함
- 군집을 몇 개의 모수로 표현할 수 있고 서로 다른 크기의 군집을 찾을 수 있음
- EM알고리즘을 이용한 모수추정에서 데이터가 커지면 수렴에 시간이 걸릴 수 있음
- 군집의 크기가 너무 작으면 추정의 정밀도가 떨어지거나 어려울 수 있음
- 이상값에 민감하므로 이상값 제거등의 사전조치가 필요함

가우시안혼합모델(GMM; Gaussian Mixture Model)
- 전체 데이터의 확률분포가 k개의 가우시안분포(정규분포)의 선형결합으로 이루어졌음을   
  가정하고 각 분포에 속할 확률이 높은 데이터간의 군집을 형성하는 방법
- 가우시안혼합모델에서는 주어진 데이터 X={𝑥1,𝑥2,…,𝑥𝑁}에 대해 적절한 k개 가우시안 분포
  의 가중치, 평균, 공분산을 추정함
- 데이터들이 k개의 가우시안 분포중에서 어디에 속하는 것이 최적인지 추정하기 위해 
  EM알고리즘을 이용할 수 있음

EM 알고리즘
- EM(Expectation Maximization), 기대값최대화) 알고리즘은 확률모델의 최대 가능도를 갖는  
  모수와 함께 그 확률모델의 가중치를 추정하고자 할 때 사용할 수 있음
-  각 데이터가 어느 분포에서 추출된 데이터인지 각 집단(잠재변수, Z)으로부터 기대값을
  구할 수 있으며 추정된 기대값을 활용하여 로그-가능도함수가 최대로 되게하는 모수를 
  찾을 수 있음
- 최대 가능도란 어떤 모수가 주어졌을때 원하는 값들이 나올 가능도를 최대로 만드는 
  모수를 선택하는 방법
- EM알고리즘은 E-단계(E-step), M단계(M-step)로 진행됨
- 단계1[E-단계]: 파라미터(모수) 설정으로 2개의 정규분포로 혼합된다고 가정할 경우 초기
  파라미터(각 정규분포의 평균과 표준편차, 가중치) 값을 임의로 설정함
- 단계2[E-단계]: Z(잠재변수)의 기대값을 계산하기 위해 설정된 파라미터 값을 가진 분포로
  부터 실제 데이터가 얼마나 나올지를 알아보기 위해 로그 가능도 함수의 기대값을 계산함
- 단계3[M-단계]: 새로운 파라미터를 추정하기 위해 2단계에서 얻은 기대값을 사용하여 
  새로운 파라미터값을 추정함
- 단계4[M-단계]: 이전 가능도에 비해 가능도 증가량이 특정 기준값보다 낮으면 가능도가
 최대가 되었다고 판단하여 알고리즘을 종료하고 그렇지 않으면 2, 3단계를 반복하여 진행함
정형  데이터  마이닝

DBSCAN의개념
- 개체들의 밀도계산을 기반으로 밀접하게 분포된 개체들끼리 그룹핑하는 알고리즘
- 군집의 개수를 미리 지정할 필요가 없고 군집밀도에 따라 군집을 서로 연결하기 때문에
 기하학적이고 노이즈가 포함된 모양의 군집분석이 가능함
- 기하학적: 도형 및 공간의 성질에 관련된
- DBSCAN은 데이터가 많은 지역을 중심으로 클러스터(군집)를 구성하며 임의적인 모양의
  군집탐색에 효과적임

DBSCAN의구성요소
- 중심점 
  - 주변 반경 내에 최소 데이터 개수 이상의 다른 데이터를 가지고 있는 데이터
  - 반경 내에 존재해야 하는 최소 데이터 개수는 일종의 초 매개변수로 설정해주어야 함
- 이웃점 
  - 특정 데이터 주변 반경 내에 존재하는 다른 데이터
- 경계점 
  - 중심점은 아니지만 중심점의 주변 반경 내에 존재하는 데이터
  - 중심점을 중심으로 하는 군집에는 포함되며 주로 군집의 외곽을 이룸
- 잡음점 
  - 중심점도 아니고 경계점 조건도 만족하지 못하는 이웃점, 이상값이라고 함

SOM(Self-Organizing Maps), 자기조직화지도
- SOM은 대뇌피질과 시각피질의 학습과정을 기반으로 모델화한 인공신경망으로 차원축소
  와 군집화를 동시에 수행할 수 있는 알고리즘
- 고차원 데이터를 한눈에 파악하기 쉬운 저차원공간에 정렬하여 지도의 형태로 나타내는
  시각화 방법임
- 입력변수의 속성을 보존한다는 특징이 있어 실제 유사한 데이터는 2차원격자에서도 
  가깝게 표현됨
- SOM은 단 하나의 전방패스(feed-forward flow)를 사용함으로써 속도가 매우 빠름
- 은닉층을 보유한 다층신경망과 달리 은닉층이 없이 데이터를 입력받는 입력층과 이를
  n개의 노드(뉴런)로 표현하고자 하는 경쟁층으로 구성되어 입력층의 모든 데이터가 
  경쟁층의 모든 노드와 완전 연결되어 있음
- 각 학습 단계 마다 임의의 프로토 타입 벡터(경쟁층의각각의뉴런)와의 거리를 
  유클리디안 거리에 의해 계산하고 비교하며 최종적으로 경쟁층에 있는 노드들 중 가장 
  가까운 하나의 노드에 도달하는데 그 노드를 승자 노드라 부름

SOM 학습 알고리즘
- 초기화
  -  초기 학습률과 임의의 가중치 벡터를 설정함
- 입력 벡터
  - 입력 벡터를 제시함
- 유사도 계산
  - 유클리드 거리를 사용하여 입력 벡터와 가중치 벡터 간의 유사도를 계산함
- 프로토타입 벡터 탐색 
  - 입력 벡터와 가장 가까운 노드(승자 노드, BMU)를 찾음
- 강도 재조정
  - BMU(입력층과 가장 가까운 경쟁층 노드)와 그 이웃 노드의 가중치를 업데이트함
반복 
  - 단계 2로 가서 지정된 반복 횟수만큼 과정을 반복함

SOM 학습 알고리즘의 장점/단점
- 장점
  - 역전파 알고리즘을 사용하지 않는 전방 패스(feed-forward) 구조이므로 속도가 매우 빠름
  - 저차원의 지도로 형상화되어 시각적인 이해가 쉬움
  - 패턴 발견 및 이미지 분석에서 성능 우수
  - 입력 데이터의 패턴을 그대로 보존하여 군집을 형성함
- 단점
  - 초기 학습률 및 초기 가중치에 많은 영향 받음
  - 경쟁층의 이상적 노드의 개수를 결정하기 어려움


## 연관분석

연관규칙
- 항목 간 조건-결과 식으로 표현되는 유용한 패턴
- 패턴, 규칙을 발견해내는 것을 연관 분석이라고 하며 흔히 장바구니 분석이라고도 불림
- 사용하는 데이터 형태는 장바구니 데이터라고 하며 장바구니 하나에 해당하는 정보를
  트랜잭션이라 함
- 연관 분석은 데이터 내부에 존재하는 항목 간 상호 관계 혹은 종속 관계 찾아내는 기법
  이라 할 수 있음

연관규칙의 장점
- 탐색적 기법
  - 데이터 간 관계를 조건반응으로 연결하고 표현하는 분석으로 장바구니 분석, 서열 분석
    이라고도 불림
- 강력한 비목적성 분석 기법
  - 목적 변수가 없어서 분석 방향이나 목적 없어도 적용 가능
- 사용한 편리한 분석데이터 형태
  - 거래 내용에 대한 데이터 변환 없이 그 자체로 이용할 수 있는 간단한 자료구조 갖는
    분석 방법
- 계산의 용이성
  - 분석을 위한 계산이 상당히 간단
- 다양한 활용성
  - 마케팅 분야에서 가장 많이 활용
  - 교차 판매, 묶음 판매 등에 활용

연관규칙의 단점
- 상당한 수의 계산과정 필요
  - 품목 수가 증가하면 분석에 필요한 계산 기하급수적으로 증가
- 적절한 품목의 결정 필요
  - 적절한 세분화로 인한 품목 결정이 장점이지만 너무 세분화된 품목은 의미 없는 결과
    도출
- 품목의 비율 차이 존재
  - 상대적으로 거래량 적은 품목은 당연히 포함된 거래 수가 적고 규칙 발견시 제외되기
    쉬움

연관규칙의 측정지표(신뢰도)
- 전체 거래 중 항목 A와 B를 동시에 포함하는 거래 비율
- 전체 구매 경향을 파악할 수 있는 지표
- 연관규칙이 나왔을 때 적용성이 있는지를 판단할 수 있고 불필요한 분석 대폭 줄임

연관규칙의 측정지표(향상도)
- 규칙이 우연에 의해 발생한 것인지를 판단하기 위해 연관성의 정도 측정하는 지표
- A와 B가 독립적으로 발생한 거래비율 중 A와 B를 함께 포함하는 거래 비율
- 1: 두 품목이 독립, 1보다 크다: 두 품목 서로 양의 상관관계, 1보다 작다: 음의 상관관계

순차 패턴
- 시간 순서에 따른 정보로 연관성을 측정해 유용한 연관규칙을 찾는 기법
