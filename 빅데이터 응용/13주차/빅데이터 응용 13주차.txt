## 시계열 예측

시계열 분석
- 시계열 분석은 연도별, 분기별, 월별 등 시계열로 관측되는 자료를 분석해 미래를 
  예측하기 위한 분석 기법임
- 시계열 분석의 주요 목적은 계절적인 패턴과 같은 외부인자 요소를 설명할 수 있는 모델
  결정하는 것임
- x축에 시간, y축에 관측값을 나타내어 추세를 빠르게 분석
- 시계열 데이터는 시간의 흐름에 따라 관측되는 자료로 대체로 독립적이지 않음

시계열 데이터 분석 절차
- 시간 그래프 작성
  - 관측값을 관측 시간에 따라 인접한 관측값을 직선으로 연결해 그래프 작성
- 추세와 계절성 제거
  - 시간 그래프 통해 나타나는 추세와 계절성을 차분을 이용해 제거하여 정상 시계열로
    변환
- 잔차 예측
  - 잔차가 서로 상관관계가 없고, 잔차의 평균은 0인 특성을 갖는지 확인함
- 잔차에 대한 모델 적합
  - 잔차에 근거해 모델 추정
- 미래 예측
  - 앞에서 제거했던 추세와 계절성을 더해 미래 예측

※ 차분: 비정상 시계열을 정상 시계열 자료로 바꾸기 위해 평균이 일정하지 않은 경우
   현시점에서 이전 시점의 자료를 빼는 방법

정상성의 개념
- 정상성은 시점에 상관없이 시계열의 특성이 일정하다는 특성
- 시계열 분석 위해 정상성을 만족해야 함

정상성의 조건
- 평균이 일정해야 하며 그렇지 않다면 차분 통해 정상화할 수 있음
- 분산이 시점에 의존하지 않음, 그렇지 않다면 변환 통해 정상화할 수 있음
- 공분산은 단지 시차에만 의존하고 시점 자체에는 의존하지 않으므로 특정 시점에서
  공분산은 동일하며 시차에 따라 공분산 값 다를 수 있음
- 시점은 특정한 시간의 관점이며 시차는 시점과 시점 간의 차이를 의미
- 정상 시계열은 데이터의 어떤 구간에서도 평균값과 분산이 일정한 시계열임

자기회귀모형(AR모형: Auto-Regressive Model)
- 현시점 자료가 p시점 전의 유한개의 과거 자료로 설명될 수 있는 모형
- Z_t = O_1*Z_t-1 + O_2*Z_t-2+...+O_p*Z_t-p+a_t
- Z_t: 현재 시점의 시계열 자료, Z_t-p: 시점 이전의 시계열 자료
- O_p: 시점이 현재 시점에 어느 정도 영향을 주는지 나타내는 모수(가중치)
- a_t: 백색잡음(시계열 분석의 오차항으로 평균이 0, 분산이 o^2인 정규분포 따름)
- 잡음은 무작위적인 변동으로 일반적으로 원인이 알려져 있지 않으며 모형에 사용하는 
  시계열 자료의 시점에 따라 1차, 2차,...,p차를 사용하지만 정상시계열 모형에선 주로 
  1, 2차를 사용

이동평균모형(MA모형: Moving Average Model)
- 주기나 불규칙성을 가지고 있는 시계열 데이터의 특성 토대로 과거 몇 개 관측치 평균해
  전반적 추세를 파악하는 방법
- 시간이 지날수록 관측치의 평균값이 지속해서 증가하거나 감소
- Z_t = a_t - O_1*a_t-1 + O_2*a_t-2 + ... + O_q*a_t-q (Z_t: 현재 시점 시계열 자료)
- O_q: 시점이 현재 시점에 어느 정도 영향 주는지 나타내는 모수(가중치), a_t: 백색잡음
- 현시점 자료를 유한개의 백색잡음 선형 결합으로 표현해 항상 정상성을 만족하므로 
  정상성 가정 필요 없음

지수평활법
- 모든 시계열 자료를 사용해 평균을 구하며 시간의 흐름에 따라 최근 시계열에 더 많은
  가중치 부여해 미래 예측하는 방법
- 단순 지수평활법, 이중 지수평활법, 홀트 모형의 종류가 있음

자기 회귀 누적 이동 평균 모형(ARIMA 모형: Auto Regressive Integrated Moving Average 
Model)
- 분기/반기/연간 단위로 다음 지표를 예측하거나 주간/월간 단위로 지표 리뷰해 트랜드를 
  분석하는 기법
- 기본적으로 비정상 시계열 모형이기 때문에 차분이나 변환 통해 AR모형이나 MA모형,
  ARMA모형으로 정상화할 수 있음

자기 회귀 누적 이동 평균 모형 차수
- ARIMA(p,d,q)모형은 차수 p,d,q가 있음
- p: AR모형과 관련 있는 차수
- d: ARIMA에서 ARMA로 정상화할 때 차분 횟수
- q: MA모형과 관련이 있는 차수

자기 회귀 누적 이동 평균 모형과 다른 모형과의 관계
- p=0: IMA(d,q)모형이라 부르고, 이 모형을 d번 차분하면 MA(q)모형이 됨
- q=0: ARI(p,d)모형이며, 이를 d번 차분한 시계열 모형이 AR(p)모형을 따르게 됨
- d=0: ARMA(p,q)모형이라 부르고, 이 모형은 정상성을 만족
- ARIMA 차수에 따른 모형
  - ARIMA(0,0,0): 백색 잡음 모형
  - ARIMA(0,1,0): 확률 보행 모형
  - ARIMA(p,0,0): 자기 회귀 모형
  - ARIMA(0,0,q): 이동 평균 모형
  - 확률보행모형: 정상성을 나타내지 않는 데이터로서 누가 봐도 알 수 있는 긴 주기 갖는
    상향 또는 하향 추세 있으며 갑작스럽고 예측할 수 없는 방향 변화가 있는 모형으로 
    금융 시계열 데이터 모형으로 활용

분해 시계열
- 시계열에 영향 주는 일반적 요인을 시계열에서 분리해 분석하는 방법
- 시계열 분리하는 분해식 사용
- Z_t = f(T_t, S_t, C_t, I_t)
- Z_t: 시계열 값, f:미지의 함수, T_t: 경향(추세) 요인, S_t: 계절요인, C_t: 순환요인, 
  I_t: 불규칙 요인
- 회귀분석적인 방법 주로 사용
- 회귀분석적 방법: 관찰된 연속형 변수들에 대해 두 변수 사이 모형 구한 뒤 적합도 
  측정해내는 분석방법

시계열 구성요소
- 추세요인
  - 자료가 어떤 특정한 형태 취하는 요인
  - 선형적 추세, 이차식 형태, 지수적 형태 등
- 계절요인
  - 고정된 주기 따라 자료가 변화하는 요인
  - 요일마다 반복, 일년 중 각 월에 의한 변화, 사분기 자료에서 각 분기에 의한 변화 등
- 순환요인
  - 알려지지 않은 주기를 가지고 자료가 변화하는 요인
  - 명백한 경제적이나 자연적인 이유 없이 알려지지 않은 주기 가지고 변화
- 불규칙 요인
  - 추세, 계절, 순환 요인으로 설명할 수 없는 회귀 분석에서 잔차에 해당하는 요인

## 정형 데이터 마이닝

데이터 마이닝
- 기업이 보유하고 있는 내부 데이터와 외부 데이터를 포함하는 모든 사용 가능한 데이터를
  기반으로 감춰진 지식, 기대하지 못했던 경향이나 새로운 규칙 등을 발견해 비즈니스
  의사결정 등에 유용한 정보로 활용하는 일련의 작업
- 대용량 데이터로부터 데이터 내에 존재하는 패턴, 관계 혹은 규칙 등을 탐색하고 통계적
  기법들을 활용하여 모델화하며 이를 통해 데이터 분석 및 더 나아가 유용한 정보, 지식
  등을 추출하는 과정

데이터 마이닝 기능
- 분류
  - 새롭게 발생한 현상 검토 후 기존 분류 및 정의된 집합에 배정
  - 주요 기법은 의사결정나무가 있음
- 추정
  - 주어진 데이터를 이용해 알려지지 않은 연속된 결과의 값 추정
  - 주요 기법은 인공 신경망 모형이 있음
- 예측
  - 미래의 양상 예측 또는 미래의 값을 추정한다는 것을 제외하면 분류나 추정과 같은 의미
  - 주요 기법은 의사결정나무, 인공 신경망 모형 등이 있음
- 연관분석
  - 아이템의 연관성을 파악하며 소매점에서 물건 배열 계획, 카탈로그 배열 및 교차 판매,
    공격적 판촉 행사 등의 마케팅 계획 수립에 적용
  - 흔히 장바구니 분석이라고 불림
- 군집
  - 이질적인 모집단을 동질성을 지닌 그룹별로 세분화
  - 미리 정의되어 있는 기준에 의존하지 않고 다른 레코드와의 유사성의 의해 그룹화
- 기술
  - 사람 및 상품에 대한 이해 증가시키기 위해 가지고 있는 의미를 설명하고 설명에 대한
    답 제공

데이터 마이닝 단계
- 소프트웨어 도입 등의 적절한 환경 구축한 후 다음 단계 수행
- 목적 정의

  - 필요시 보강 작업 거쳐 데이터 마이닝 기법 적용에 문제가 없도록 충분한 데이터 양

  - 분석 전문가의 전문성이 필요
- 검증

    적용하고 경영진에게 기대 효과를 알릴 수 있도록 보고서 작성

##분류 분석

분류 분석
- 종속변수가 알려진 다변량 자료를 이용해 모형을 구축하고 이를 통해 새로운 자료에 대한
  예측 및 분류 수행하는 것이 목적
- 예측 모형의 주 목적은 반응변수(종속변수)가 범주형인 경우 새로운 자료에 대한 범주
  분류(범주 예측)이며, 반응변수가 연속형인 경우 반응 변수를 예측하는 것
  예측과 분류는 유사한 의미로 사용

로지스틱 회귀 분석
- 독립변수가 수치형이고 반응변수가 범주형인 경우 적용되는 회귀분석모형
- 새로운 설명변수의 값이 주어질 때 반응변수의 각 범주에 속할 확률이 얼마인지를 추정해
  추정 확률을 기준치에 따라 분류하는 목적
- 모형의 적합을 통해 추정된 확률을 사후 확률로 부름
  - 사후 확률: 사건 발생 후 그것이 어떤 원인이라고 생각되는 확률
- 사진
- 대상이 되는 데이터의 종속변수의 결과가 0과 1 두 개의 경우만 존재
- 식은 독립변수가 -무한, +무한의 어느 숫자이든 상관없이 종속변수 또는 결과값이
  항상 범위 [0,1] 사이에 있도록 하는데 이는 로짓(Logit)변환을 수행함으로써 얻어짐
  - [a,b] -> a<=범위<= b이고 (a,b) -> a<범위 <b
- 분석 대상이 되는 종속 변수인 0, 1은 로짓을 이용해 연속변수인 것처럼 바꿔줌으로써
  활용할 수 있음
- 그러나 바로 로짓으로 변환하지 못하고 먼저 오즈, 오즈비를 거쳐 로짓으로 변환해야 함
- exp(B_1)의 의미는 나머지 변수(x_2,...,x_k)가 주어질 때 x_1이 한 단위 증가할 때마다 성공
  (Y=1)의 오즈가 몇 배증가하는지 나타내는 값
- 오즈(Odds)
  - 오즈는 특정 사건이 발생할 확률과 그 사건이 발생하지 않을 확률의 비율
  - Odds(p) = p/1-p (p: 특정 사건의 발생 확률)
- 로짓 변환
  - 오즈에 로그를 취한 함수로 입력값의 범위가 [0,1]일 때 출력값의 범위를 (-무한, +무한)
    로 조정
  - Logit(p) = log(p/1-p) = log Odds(p)
  - 로짓 변환도 [0,1[에 대한 확률값으로 (-무한, +무한)의 값을 갖는다는 한계점이 있어
    이러한 한계를 극복하기 위해 로짓 함수의 식을 조작해 최종적으로 시그모이드 함수를
    사용해 로지스틱 회귀 분석 구현 

시그모이드 함수
- S자형 곡선 갖는 수학 함수
- 로짓 함수에 역함수를 취하면 시그모이드 함수
- simoid(x) = 1/1+e^-x (x의 값이 (-무한, +무한)일 때 y값은 [0,1]의 값을 가짐)
- x값이 무한에 가까울수록 1에 가깝고 x값이 -무한에 가까울수록 0에 가까움

검정
- 로지스틱 회귀분석의 유의성 검정은 카이제곱 검정 이용
- 영 이탈도, 잔차 이탈도의 값으로 카이제곱 검정 실시
- 이탈도: 모형이 데이터를 얼마나 설명하지 못하는지에 대한 척도
- 영 이탈도: 독립변수 없이 상수항만 있는 모형의 이탈도
- 잔차 이탈도: 선택된 모형의 이탈도

인공신경망
- 사람 두뇌의 신경세포인 뉴런이 전기신호를 전달하는 모습을 모방한 기계학습 모델
- 입력값을 받아 출력값을 만들기 위해 활성화 함수를 사용
- 가중치를 알아내는 것이 목적
- 1세대
  - 인공신경망이라는 개념 최초 제안
  - 퍼셉트론이라는 선형 분류가 가능한 순방향 신경망을 제안
  - XOR 선형 분리 불가 문제 발생
  ※ 순방향 신경망: 입력데이터가 입력층->은닉층->출력층 순서로 전파되어 판별함수 
     값으로 변환되는 신경망
  - 컴퓨터는 2가지의 디지털 값, 즉 0과 1을 입력해 하나의 값을 출력하는 회로가 모여 만들
    어지는데 이를 게이트라 함
  - AND, OR, XOR 게이트 존재
  - XOR의 경우 선을 그어 구분할 수 없음
- 2세대
  - 다층 퍼셉트론과 역전파 알고리즘 등장
  - 은닉층 통해 XOR 문제 해결
  - 과적합 문제, 사라지는 경사 현상 문제 발생
  ※다층퍼셉트론: 입력층과 출력층 사이에 하나 이상의 은닉층을 두어 비선형적으로 
    분리되는 데이터에 대해 학습이 가능한 퍼셉트론
  ※ 역전파알고리즘: 역방향으로 가중치 갱신을 통해 오차를 최소화 하도록 학습시키는 
     알고리즘
  ※ 과적합문제: 데이터가 많지 않은 경우 특정 학습데이터에만 학습이 잘 되어 새로운 
     데이터에 대한 추론성능이 낮아지는 현상
  ※ 사라지는 경사현상 문제: 은닉층의 층수를 늘릴 때 데이터가 사라져 학습이 잘 되지 
     않는 현상
- 3세대
  - 알파고와 이세돌의 바둑 대결로 인공지능 부각
  - 딥러닝(CNN, RNN 등) 활용
  - 과적합 문제 및 기울기 소실 문제 해결
  ※ 기울기 소실 문제: 오차 역전파에서 계산 결과와 정답과의 오차를 통해 가중치를 
     수정하는데 입력층으로 갈 수록 기울기가 작아져 가중치들이 업데이트 되지 않아 
     최적의 모델을 찾을 수 없는 문제
  ※ 계층을 이동할 때마다 노드의 활성화 함수의 미분값을 곱하게 되는데 시그모이드 
     함수는 미분값이 0~0.25로 입력층으로 갈수록 0에 가까워져 기울기가 사라져 가중치가
     적용 되지 않음

퍼셉트론
- 인간의 신경망에 있는 뉴런의 모델 모방해 입력층, 출력층으로 구성한 인공신경망 모델
- 입력값, 가중치, 순입력함수, 활성화 함수, 예측값으로 되어 있음
- 입력값과 가중치를 순 입력함수에서 각각 곱하고 모두 더함
- 순 입력함수 값을 활성화 함수의 임계값과 비교해 예측값을 1또는 -1로 출력
- 활성화 함수의 예측값이 실제 결과와 다를 경우 가중치 업데이트하며 위 과정 반복

다층 퍼셉트론
- 입력층과 출력층 사이에 하나 이상의 은닉층을 두어 비선형적으로 분리되는 데이터에
  대해 학습이 가능한 퍼셉트론
- 입력층, 은닉층, 출력층으로 구성하고 역전파 알고리즘을 통해 다층으로 만들어진
  퍼셉트론의 학습이 가능
- 다층 퍼셉트론에서 활성화 함수로 시그모이드 함수 사용

다층 퍼셉트론의 문제점
- 과대 적합
  - 훈련 데이터가 부족한 경우 훈련 데이터에는 잘 동작하지만 실제 데이터에는 예측을
    못하는 문제점 존재
  - 훈련 데이터 부족으로 인한 과대적합은 빅데이터 시대가 열리면서 데이터 확보가 쉬워져
    해결됨
- 기울기 소실
  - 역전파 알고리즘은 학습하는 과정에서 출력층 -> 은닉층 -> 입력층 방향으로 편미분을
     진행함
  - 다층 퍼셉트론의 활성화 함수인 시그모이드 함수는 편미분을 진행할수록 0으로 근접
    해져 기울기가 소실되는 문제점이 발생
  - 기울기 소실은 시그모이드 함수 대신 ReLU함수를 사용해 문제 해결

뉴런 활성화 함수
- 순 입력함수로부터 전달받은 값을 출력값으로 변환해 주는 함수
- 활성화 함수의 종류에는 계단함수, 부호함수, 선형함수, 시그모이드 함수, than함수, ReLU
  함수 등이 있음
- 시그모이드 함수는 기울기 소실의 원인이었으며 ReLU함수를 통해 기울기 소실 문제 해결
- 사진

순전파
- 입력층에서 출력층까지 정보 전달되는 과정
- 입력층에서 은닉층 방향으로 이동하면서 각 입력값의 가중치 곱함
- 은닉층에서는 가중치가 반영된 입력값의 합계를 활성화 함수로 계산하고 결과값을
  출력층으로 전달

손실함수
- 실제값과 예측값의 차이를 비교하는 지표
- 값이 낮을수록 학습이 잘 된 것이라고 볼 수 있고 정답과 알고리즘 출력 비교할 때 사용
- 인공신경망 학습에서 최적의 매개변수를 탐색할 때 손실함수 값을 가능한 작게 하는
  매개변수 값을 찾음
- 인공신경망의 가중치 매개변수는 훈련 데이터와 학습 알고리즘에 의해 자동으로 획득

경사 하강법
- 기울기를 낮은 쪽으로 계속 이동시켜 최적의 매개 변수를 찾는 기법으로 함수의 기울기를
  구하고 경사의 절대값이 낮은 쪽으로 계속 이동시켜 극값에 이를 때까지 반복시킴
- 학습률은 갱신하는 양(한 번 학습할 때 학습해야 하는 양)으로 사람이 직접 설정하는 초
  매개변수

경사 하강법 한계
- 전체 데이터 모두 사용해 기울기 계산하기 때문에 학습하는 데 많은 시간이 필요하며 
  랜덤하게 선택된 가중치의 위치가 지역 최소 점에 근접해 있으면 전역 최소값이 아닌
  지역 최소값에 수렴할 수 있음
- 경사 하강법의 단점 극복 위해 확률적 경사 하강법, 모멘텀 등의 매개변수 최적화 기법
   사용

의사결정나무
- 의사결정 규칙을 나무 구조로 나타내 전체 자료를 몇 개의 소집단으로 분류하거나 예측
  하는 분석 방법
- 분석 대상을 분류함수를 활용해 의사결정 규칙으로 이루어진 나무 모양으로 그리는 기법
  - 분류함수: 어느 모집단에서 추출된 것인지 모르는 새로운 데이터가 관측되었을 때 이 
    데이터를 여러 모집단 중 어느 하나의 모집단으로 분류해주기 위해 분류의 기준으로
    사용되는 함수
- 구조는 연속적으로 발생하는 의사결정 문제를 시각화해서 의사결정이 이루어지는 시점과
  성과 파악을 쉽게 해줌
- 의사결정나무 기법의 해석이 쉬운 이유는 계산 결과가 의사결정나무에 직접 나타나기
  때문임

의사결정나무 구성요소
- 뿌리마디, 자식마디, 부모마디, 끝마디, 중간마디, 가지, 깊이 등의 요소로 구성
- 가지분할은 나무의 가지를 생성하는 과정이며 가지치기는 생성된 가지를 잘라내
  모형을 단순화하는 과정
- 부모마디
  - 주어진 마디의 상위에 있는 마디
- 자식 마디
  - 하나의 마디로부터 분리되어 나간 2개 이상의 마디들
- 뿌리마디
  - 시작되는 마디로 전체 자료 포함
- 끝마디
  - 앞 노드라고도 불림
  - 자식 마디가 없는 마디
- 중간 마디
  - 부모 마디와 자식 마디가 모두 있는 마디
- 깊이
  - 뿌리 마디부터 끝마디까지의 중간 마디들의 수

의사결정나무 해석력과 예측력
- 은행 신용평가에서는 평가 결과 부적격 판정이 나온 경우 대상자에게 부적격 이유를
  설명해야 하므로 의사결정나무의 해석력에 집중
  - 해석력은 결과 해석하고 설명할 수 있는 정도
- 기대 집단의 사람 중 가장 큰 반응을 보일 상품 구매 고객의 모집방안을 예측하고자 하는
   경우 의사결정나무의 예측력에 집중
  - 예측력은 실제 예측의 정확도 나타내는 정도

의사결정나무의 분석과정
- 설명변수 선택
  -목표변수와 관계가 있는 설명변수들 선택
- 의사결정나무 생성
  - 분석의 목적과 자료구조에 따라서 적절한 분리기준과 정지 규칙을 정해 의사결정나무
    생성
- 가지치기
  - 부적절한 나뭇가지는 가지치기로 제거
- 모형 평가
  - 이익, 위험, 비용 등을 고려해 모형 평가
- 분류 및 예측
  - 데이터의 분류 및 예측에 활용

의사결정나무 분리 기준
- 하나의 부모 마디로부터 자식 마디들이 형성될 때 입력변수의 선택과 범주의 병합이
  이루어지는 기준 의미
- 어떤 입력변수 이용해 어떻게 분리하는 것이 목표변수의 분포를 가장 잘 구별해주는지
  파악해 자식 마디가 형성되는데 목표변수 분포를 구별하는 정도를 순수도, 또는 불순도에
  의해 측정
- 목표변수가 이산형인 경우 분류나무, 연속형인 경우 회귀나무로 구분되며 이에 따라 다른
  분리 기준을 사용함
- 분리 기준
  - 카이제곱 통계량의 p-값: p-값이 가장 작은 예측변수와 그 당시 최적 분리 통해 자식
    마디 형성
  - 지니 지수: 불순도를 측정하는 하나의 지수로 지니 지수를 가장 많이 감소시켜주는 예측
    변수와 그 당시 최적 분리 통해 자식 마디 선택
  - 엔트로피 지수: 엔트로피 지수가 가장 작은 예측변수와 그 당시 최적 분리 통해 자식
    마디를 형성
  - 분산 분석에서 F통계량: p-값이 가장 작은 예측변수와 그 당시 최적 분리 통해 자식
    마디 형성
  - 분산의 감소량: 오차 최소화하는 것과 같은 기준으로 분산의 감소량을 최대화하는
    기준의 최적 분리 통해 자식 마디 형성

의사결정나무 정지 규칙
- 더는 분리가 일어나지 않고 현재 마디가 끝마디가 되도록 하는 규칙
- 의사결정나무의 깊이를 지정하거나, 끝마디 데이터 수의 최소 개수를 지정할 수 있음

의사결정나무 가지 치기
- 분류 오류를 크게 할 위험이 높거나 부적절한 추론 규칙을 가지고 있는 가지 또는 불필요
  한 가지를 제거하는 과정
- 의사결정나무에서 너무 큰 나무 모형은 자료를 과대 적합하고 너무 작은 나무 모형은
  과소 적합할 위험성 있음

의사결정나무 불순도의 여러가지 척도
- 목표변수가 이산형 변수인 의사결정나무의 분류 규칙을 선택하기 위해 카이제곱 통계량,
  지니 지수, 엔트로피 지수 활용
- 카이제곱통계량: 값이 클수록 순수도가 낮다고 볼 수 있음
- 지니 지수: 노드의 불순도 나타냄, 값이 클수록 순수도 낮음
- 엔트로피 지수: 무질서 정도에 대한 측정값, 값이 클수록 순수도 낮음

의사결정나무 알고리즘
- CART(이진분할) 
  - 각 독립변수를 이분화하는 과정 반복해 이진 트리 형태를 형성함으로써 분류를 수행
  - 불순도를 지니지수로 계산하는 알고리즘
- C4.5와 C5.0
  - CART와는 다르게 각 마디에서 다지분리를 할 수 있으며 범주형 독립변수에 대해서 범주
    수만큼 분리가 일어남
  - 불순도를 엔트로피 지수로 계산하는 알고리즘
- CHAID(다지분할)
  - 가지치기하지 않고 나무가 적당한 크기에서 성장을 중지하며 독립변수가 이산형 변수
  - 불순도의 척도로 카이제곱 통계량 사용
- QUEST
  - 변수의 선택에서 범주의 개수가 많은 범주형 변수로의 편향이 심각한 CART의 문제점
    개선한 알고리즘

의사결정나무의 장점
- 해석의 용이성
  - 나무 구조에 의해 모형이 표현되기 때문에 모형을 사용자가 쉽게 이해 가능
  - 새로운 개체에 대한 분류 또는 예측을 하기 위해서 뿌리 마디로부터 끝마디까지 단순히
    따라가면 되기에 새로운 자료에 모형 적합시키기 쉬움
  - 나무 구조에서 어떤 입력변수가 목표변수를 설명하기 더 중요한지 쉽게 파악 가능
- 상호작용 효과의 해석 가능
  - 두 개 이상의 변수가 결합하여 목표변수에 어떻게 영향을 주는지 쉽게 파악 가능
  - 유용한 입력변수나 상호작용의 효과 또는 비선형성을 자동으로 찾아냄
- 비모수적 모형
  - 선형성이나 정규성 또는 등분산성 등의 가정을 필요로 하지 않은 비모수적인 방법
  - 순서형 또는 연속형 변수는 단지 순위만 분석에 영향을 주기 때문에 이상값에 민감하지
    않음
- 유연성과 정확도가 높음
  - 대용량 데이터 빠르게 만듬
  - 설명변수나 목표변수에 수치형 변수와 범주형 변수 모두 사용 가능
  - 모형 분류 정확도 높음

단점
- 비연속성
  - 연속형 변수를 비연속적인 값으로 취급하기 때문에 분리의 경계점 근방에서 예측 오류가
    클 가능성 있음
- 선형성 또는 주 효과 결여
  - 선형모형에서 주효과는 다른 예측변수와 관련시키지 않고서도 각 변수의 영향력을 해석
    할 수 있다는 장점이 있는데 의사결정나무에서는 선형 또는 주효과 모형에서와 같은
    결과를 얻을 수 없다는 한계점 있음
- 비안정성
  - 훈련용 데이터에만 의존하는 의사결정나무는 새로운 자료의 예측에는 불안정하여 과대
    적합이 발생할 가능성 있음
  - 분석용 자료의 크기가 너무 작은 경우나 너무 많은 가지를 가지는 의사결정나무를 얻는
    경우 비안정적임
