## R 기초와 데이터 마트

분석 환경의 이해
- 뉴질랜드 통계학자 로스 이하카와 캐나다 통계학자인 로버트 젠틀맨에 의해 1995년
  제작된 언어로 다양한 분야에서 사용되는 오픈소스 통계 분석 도구
- 특징
  - 오픈소스: 오픈소스 소프트웨어이므로 자유로운 사용 가능
  - 인터프리터 언어: 프로그램 문장을 하나씩 번역하고 실행하는 언어
  - 대소문자 구별: 식별자, 명령어 등 대소문자 구분
  - 범용성: Microsoft Windows, Mac OS, Linux 등 다양한 OS 지원
  - 다양한 기능: 다양한 최신 통계 분석과 데이터마이닝 기능 제공

변수 (잘못된 변수 구분 문제 나옴)
- 다양한 값을 지니고 있는 하나의 속성
- 문자, 숫자, 언더바 등을 조합해 생성
- 첫 글자는 마침표 또는 문자로 시작해야 함, 마침표로 시작 시 뒤에 숫자 불가능
- 변수명은 대소문자 구분

데이터 타입
- 프로그래밍 언어에서 실수형, 문자형과 같은 여러 종류 데이터 식별하는 형태
- 기본 타입으로 숫자형, 문자형, 논리형이 있음
  - 숫자형: 정수, 실수를 저장하는 객체 형식
  - 문자형: 문자, 문자열을 저장하는 객체 형식
  - 논리형: 논리값 TRUE, FALSE를 저장하는 객체 형식
  - NA(Not Available): 데이터 값이 없음, 공간을 차지하는 결측값
  - NULL: 변수가 초기화되지 않는 경우, 공간 차지하지 않는 결측값
  - NaN(Not a Number): 수학적으로 계산할 수 없는 값
  - INF(INFinite): 무한대

대입 연산자
- 변수 선언하고 값 할당할 때 대입 연산자 사용
  - '=': 왼쪽의 변수에 오른쪽 값 대입
  - '<-', '<<-': 왼쪽 변수에 오른쪽 값 대입
  - '->', '->>': 오른쪽의 변수에 왼쪽 값 대입

비교 연산자
- 대입 연산자에 의해 할당된 값과 변수, 숫자, 문자 및 논리값 비교
  - '==': 두 값 같은지 비교
  - '<','>': 두 값 초과와 미만 비교
  - '!=': 두 값 다른지 비교
  - '<=', '>=': 두 값 이상과 이하 비교
  - 'is.character': 문자형인지 비교
  - 'is.numeric': 숫자형인지 비교
  - 'is.logical': 논리형인지 비교
  - 'is.na': NA인지 비교

산술 연산자
- 두 숫자형 타입의 계산을 위한 연산자로 다양한 연산 가능
  - '+, -, *, /': 사칙연산
  - '%/%': 두 숫자 나눗셈 몫
  - '%%': 두 숫자 나눗셈 나머지
  - '^', '**': 거듭제곱

기타 연산자
- 논리값 계산 위한 연산자로 부정 연산자, AND 연산자, OR 연산자가 있음
  - '!': 현재 논리값에 반대
  - '&': 두 값이 모두 참일 때만 참
  - '|': 둘 중 하나의 값만 참이라도 참

객체
- 객체의 종류로 벡터, 행렬, 배열은 한 가지 타입을 가진 원소들만 저장할 수 있으며, 리스트
  데이터프레임은 다양한 타입 가진 원소들 저장 가능
- 1차원: 벡터, 리스트
- 2차원: 행렬, 데이터 프레임
- 3차원: 배열

벡터
- 기본적인 데이터 단위로 같은 데이터 타입 가진 원소들만 저장 가능
- 다른 타입의 데이터 섞어 벡터에 저장 시 이들 데이터는 한 가지 타입으로 형태 반환
- 벡터 데이터 내 들어갈 수 있는 원소는 숫자, 문자, 논리 연산자 등이 될 수 있음
- 숫자로 이루어진 벡터는 숫자 벡터, 문자로 이루어진 벡터는 문자 벡터
- R에서 다루는 데이터 구조 중 가장 단순한 형태는 명령어 C를 이용해 선언 가능
- C는 combine(결합)을 의미
- 여러 타입을 결합하면 우선순위는 문자형 -> 숫자형 -> 논리형임
- rep 함수는 지정한 벡터를 반복 횟수만큼 반복함
  - rep(x,times,...): 첫번째 인수를 두 번째 인수만큼 반복하는 숫자 벡터 생성
  - X: 벡터, times: 벡터 전체 반복 횟수 
- seq 함수: 첫 번째 인수부터 두 번째 인수까지 1씩 증가하는 수열의 숫자 벡터 생성
  - 옵션: by=n(n씩 증가하는 수열생성), length=m(전체수열 개수가 m개가 되게 자동 증가)
- paste 함수: 입력받은 문자열들 하나로 붙여주며 'sep'옵션으로 붙이고자 하는 문자열들
  사이에 구분자 삽입 가능
- 벡터에 저장된 값의 위치를 인덱스로 사용해 각 요소 접근 가능
  - 벡터[n]: 타 언어와 다르게 인덱스 1부터 시작
  - 벡터[-n]: n번째 요소 제외하고 출력
  - 벡터[조건문]: 조건문 만족하는 요소 출력
  - 벡터[a:b]: a번째 요소부터 b번째 요소까지 출력
- 벡터와 벡터간 사칙연산 수행 시 연산되는 벡터 길이 같아야 함
- substr 함수: 문자열 일부 추출
  - substr(x, start, stop)
  - x: 문자형 벡터
  - start: 시작 위치
  - stop: 종료 위치

리스트
- 리스트는(키, 값) 형태로 데이터 저장하는 R의 모든 객체 담을 수 있는 데이터 구조
- 리스트는 lisdt(key=value, key = value,...) 형태로 데이터 나열해 정의
- 리스트는 각 각체에 이름 지정하여 저장 가능, 객체 길이 달라도 됨

행렬
- 행과 열을 갖는 mxn 형태의 직사각형 데이터 나열한 데이터 구조
- matrix 함수: matrix(data, nrow, ncol, byrow, dmnames)
  - data: 행렬에 저장할 데이터(벡터)
  - nrow: 행의 개수(기본값은 1)
  - ncol: 열의 개수(기본값은 1)
  - byrow: 행렬의 데이터 입력순서(기본값은 FALSE) -> True는 행 기준, False는 열 기준
  - dimnames: 행과 열의 이름 리스트
- 행렬 함수
  - dim(x): 행렬의 차원 확인
  - nrow(x): 행렬 행의 수 확인
  - ncol(x): 행렬 열의 수 확인
  - x[m,n]: m행 n열의 원소 추출
  - x[m,]: x행렬 m행에 접근
  - x[,n]: x행렬 n행에 접근
  - rownames(x): x행렬의 행 이름 출력
  - colnames(x): x행렬의 열 이름 출력
- 행렬에 대해 곱 연산 수행 시 스칼라 곱의 결과 얻어낼 수 있음

데이터프레임
- 각 행이 하나의 관측치 의미하고 각 열이 하나의 변수라고 가정 가능

배열
- 배열은 3차원 또는 n차원까지 확장된 형태의 다차원 데이터
- array 함수는 배열을 생성하는 함수 -> array(data, dim, dimnames)로 수행
  - data: 배열에 저장할 데이터 지정, 데이터 지정하지 않을 시 NA 값으로 대체
  - dim: 배열의 차원을 c()로 묶어 지정
  - dimnames: 배열의 차원 이름 지정, 이름 지정하지 않을 시 기본값은 NULL

데이터 결합
- rbind, bind 함수 사용해 벡터 합쳐서 행렬 만들 수 있음
- rbind: 벡터, 행렬, 데이터 프레임 행 서로 결합해 새로운 행렬 또는 데이터 프레임 생성
- bind: 벡터, 행렬, 데이터 프레임 열 서로 결합해 새로운 행렬 또는 데이터 프레임 생성

반복문
- 대표적인 제어문 중 하나로 특정 부분의 코드가 반복적으로 수행
- for, while

조건문
- 참과 거짓에 따라 특정 코드가 수행될지 혹은 수행되지 않을지를 결정

패키지
- 함수, 데이터, 코드 등을 모아놓은 집합
- install.packages 함수로 패키지 설치 후 library 함수로 패키지를 불러옴

데이터 전처리 패키지
- 데이터 전처리 패키지는 전처리 작업에 필요한 함수 모아놓은 패키지
- plyr: 원본 데이터 분석하기 쉬운 형태로 나눠서 다시 새로운 형태로 만들어줌
  - 데이터 분할(split), 원하는 방향으로 특정 함수 적용(apply), 그 결과 재조합(combine)
  - ply형태이고 첫번째 글자는 입력데이터 형태, 두번째는 출력데이터 형태임
- reshape2: melt와 cast함수 사용
  - melt: 특정 변수 기준으로 녹여서 나머지 변수에 대한 세분화된 데이터 만듬
  - cast: 녹은 데이터 모양 다시 재조합
- datatable: 연산속도가 매우 빨라 크기가 큰 데이터 처리하거나 탐색하는데 효과적
  - 데이터 프렝미과 유사하지만 보다 빠른 grouping 가능
  - 데이터 테이블은 데이터 프레임으로 변환해서 사용 가능
  - 데이터 프레임과 동일하게 취급되므로 데이터 프레임에 적용할 수 있는 함수 사용 가능
  - data.table(tag=value,...): tag는 변수명, value는 값

데이터 변환
- as.character(x): 문자형
- as.numeric(x) : 숫자형
- as.double(x) : 실수형
- as.logical(x) : 논리형
- as.integer(x) : 정수형, x가 실수(예: x=3.14 → 3)이면 소수점을 버림
- as.data.table(x): 데이터 테이블로 변환함
- as.Date(x,format): x를 format에 맞춰 인식한 후 연도-월-일 순으로 변환
- as.list(x): 리스트로 변환
- as.matrix(x): 행렬로 변환
- as.vector(x): 벡터로 변환, 동일 자료형 가져야 함

## 데이터 마트

데이터 마트의 개념
- 데이터 마트는 데이터의 한 부분으로 특정 사용자가 관심을 두는 데이터들을 주체별,
  부서별 및 목적별로 모아놓은 비교적 작은 규모의 데이터 웨어하우스
- 잘 정리된 데이터마트의 개발은 효율적이고 신속한 모델링을 실시하는 경우 도움을 줌
  - 모델링은 다양한 분석기법을 적용해 모델을 개발하는 과정을 의미

데이터 저장소 종류
- 데이터 웨어하우스
  - 사용자의 의사결정에 도움 주기 위해 데이터베이스에 축적된 데이터를 공통 형식으로
    변환해 관리하는 데이터베이스
- 데이터 마트
  - 전사적으로 구축된 데이터 속의 특정 주제, 부서 중심으로 구축된 작은 규모의 데이터
    웨어하우스
- 데이터 레이크
  - 정형, 반정형, 비정형 데이터를 비롯한 모든 가공되지 않은 다양한 종류의 데이터를
    저장할 수 있는 시스템
- 데이터 댐
  - 모든 산업의 데이터를 데이터 댐에 쌓는다는 의미로 어떤 값을 포함하고 있는 가공되지
    않은 1차 자료를 모아놓은 저장소

## 결측값 처리와 이상값 검색

데이터 탐색
- 데이터 특성을 파악하고 데이터에 대한 통찰을 얻기 위한 다양한 각도의 접근 방법
- head 함수
  - x: 출력 위한 객체
  - n: 출력할 데이터 개수(기본값 6)
- str(object) 함수
  - object: 데이터 속성 출력하기 위한 객체
- summary(object) 함수
  - 요약통계량을 출력하는 함수
  - 수치형 변수의 경우 최소값, 1사분위수, 중위수, 평균, 3사분위수, 최대값 보여줌
  - 범주형 변수의 경우 각 범주에 대한 빈도수 출력
  - 변수 중 결측값이 있는 경우 결측값 개수 보여줌
  - object: 요약 통계량을 위한 객체

결측값
- 입력이 누락된 값으로 가능하면 제외하고 처리하는 것이 적합
- 결측값 자체가 의미 있는 경우도 가끔 존재
- 결측값에 대한 처리가 전체 작업속도에 많은 영향을 주므로 자동화하면 효율성 향상

결측값 확인
- 결측값 입력 방법은 NA 이용
- is.na(x): 데이터의 각 행과 변수별로 결측값 있으면 TRUE, 아니면, FALSE를 출력
- complete.cases(x): 데이터 행별로 결측값 없으면 TRUE, 있으면 FALSE 출력

결측값 처리 방법
- 단순 대치법: 결측값을 그럴듯한 값으로 대체하는 통계적 기법
  - 통계량의 효율성 및 일치성 등의 문제를 부분적으로 보완
  - 대체된 자료는 결측값 없이 완전한 형태
- 다중 대치법: 단순 대치법을 m번 수행해 m개의 가상적 완전한 자료 만들어서 분석
  - 단순 대치법의 추정량 표준오차의 과소추정 또는 계산의 난해성 문제 보완
  - 대치 -> 분석 -> 결합의 3단계 구성
  - 대치: 다양한 대치 방법 이용해 가상의 완전한 자료 m개 데이터세트 생성
  - 분석: m개 데이터세트 각각에 대한 통계분석(모수추정치, 표준오차 등)을 실시
    - 모수: 집단을 대표하는 값
  - 결합: 분석 단계에서 생성된 m개의 추정량과 분산의 결합을 통한 통계적 추론

단순 대치법 종류
- 완전 분석법
  - 불완전한 자료는 모두 무시하고 완전하게 관측된 자료만 사용해 분석
- 평균 대치법
  - 관측이나 실험으로 얻어진 자료의 평균값으로 결측값 대치
  - 비 조건부 평균 대치법: 자료의 평균값 사용
  - 조건부 평균 대치법: 결측값 있는 변수를 종속변수로 해 회귀분석 실시
- 단순확률 대치법
  - 평균 대치법에서 대치값을 어떤 적절한 확률값을 부여한 후 대치하는 방법
  - 표준오차(평균의 표준편차)에 대한 과소추정 문제를 보완하고자 고안하였지만 간단한
    경우를 제외하고 추정량의 표준오차 계산 자체가 어려움

이상값
- 관측된 데이터의 범위에서 많이 벗어난 아주 작은 값이나 큰 값을 의미
- 입력의 오류 또는 데이터처리 오류 등의 이유로 특정 범위에서 벗어난 데이터 값

이상값 검색 방법
- 평균과 표준편차 이용한 ESD 방법과 사분위수를 이용한 방법 이용
- 데이터 분석에서 전처리 방법 결정할 때 부정 사용 방지 시스템(FDS)의 규칙발견에 사용
  가능
- ESD는 평균으로부터 표준편차(o)의 k배 떨어진 값을 이상값으로 판별하는 방법으로
  k=3으로 하는 것이 일반적임(표본평균-3*o<데이터<표본평균+3*o(정상범주))
- ESD는 평균을 이용해 이상값에 민감하다는 단점 존재
- 기하평균을 이용하는 방법은 기하평균으로부터 표준편차의 2.5배보다 떨어져 있는 값을
  이상값으로 판단함
- 기하평균-2.5*o < 데이터 < 기하평균+2.5*o(정상범주)
- 기하평균: n개의 양수 값을 모두 곱한 것의 n 제곱근
- 2,3,6의 기하평균 -> (2*3*6)^1/3 = 33
- 사분위수를 이용한 방법으로 제1사분위수, 제3사분위수를 기준으로 사분위 범위의
  1.5배 떨어져 있는 값을 이상값으로 판단
- 1사분위수 - 1.5 * (3사분위수 - 1사분위수) < data < 
   3사분위수 +1.5*(3사분위수 - 1사분위수)(정상범주)
- 사분위수를 이용하므로 ESD와 달리 이상값에 민감하지 않음
