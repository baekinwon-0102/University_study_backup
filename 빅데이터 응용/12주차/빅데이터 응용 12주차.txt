## 기초 통계 분석

기술 통계
- 데이터 분석 목적으로 수집된 데이터를 확률, 통계적으로 정리, 요약하는 기초적 방법
- 분석의 초기 단계에서 데이터 분포의 특징을 파악하려는 목적으로 산출

중심위치 측도
- 모평균: u = 1/n sigma(N, i=1) x_i (단, N은 모집단 개수)
- 표본평균: x = 1/n sigma(N, i=1) x_i (단, n은 표본집단 개수)
- 중위수: 데이터를 오름차순으로 정렬해 중앙에 위치한 데이터로 이상값에 대한 영향 미미
- 중위수는 데이터가 홀수개일때는 n+1/2번째 값이며 짝수개일때는 n/2, n/2+1번째 값의
  평균
- 최빈수: 데이터 중 빈도수가 가장 높은 데이터
- 사분위수: 모든 데이터를 순서대로 배열하였을 때 4등분한 지점에 있는 값
  - 제1사분위수: 데이터를 오름차순해 25% 지점에 있는 값
  - 제2사분위수: 데이터를 오름차순해 50% 지점에 있는 값
  - 제3사분위수: 데이터를 오름차순해 75% 지점에 있는 값

산포 측도
- 산포도는 주어진 자료가 흩어진 정도 나타내는 값
- 분산은 각 데이터가 평균으로부터 얼마나 떨어져 있는지 나타내는 값
- 표준편차는 분산에 제곱근을 취한 값
- 모분산: o^2 = sigma (N, i=1) (x_i-u)^2/N ( 단, N은 모집단 개수)
- 표본분산: S^2 = sigma(n, i=1) (x_i - bar x)^2/n-1 (단, n은 표본집단 개수) 
- 모표준편차: o = 루트(sigma(N, i=1) (x_i-u)^2/N) (단, N은 모집단 개수)
- 표본표준편차: S = 루트(sigma(n, i=1) (x_i - bar x)^2/n-1) (단, n은 표본집단 개수) 
- 범위: 데이터 중 최대값과 최소값 차이(R=x_max - x_min)
- 사분위범위(IQR): Q3-Q1(단, Q3는 제3사분위수, Q1은 제1사분위수)
- 사분편차: 사분위범위의 절반 값(IQR/2 = Q3-Q1/2)
- 평균 절대 편차: 평균과 개별 관측치 차이의 평균으로 평균 편차 또는 절대 편차라고 불림
- 모평균 절대편차: MAD = 1/N sigma(N, i=1) |x_i-u|
- 표본평균 절대편차: MAD = 1/n sigma(n, i=1) |x_i - bar x|

데이터 분포
- 데이터 분포의 형태와 대칭성을 설명할 수 있는 통계량은 첨도와 왜도가 있음
- 첨도: 데이터 분포의 뾰족한 정도를 설명하는 통계량
  - 첨도=0: 데이터 분포가 표준정규분포와 뾰족한 정도 같음
  - 첨도>0: 데이터 분포가 표준정규분포보다 더 뾰족함
  - 첨도<0: 데이터 분포가 표준정규분포보다 덜 뾰족함
- 왜도: 데이터 분포의 기울어진 정도를 설명하는 통계량
  - 왜도=0: 좌우대칭, 최빈수=중위수=평균
  - 왜도>0: 우측으로 긴 꼬리형태, 최빈수<중위수<평균
  - 왜도<0: 좌측으로 긴 꼬리형태, 평균<중위수<최빈수

회귀분석
- 하나 이상의 독립변수들이 종속변수에 미치는 영향을 추정할 수 있는 통계기법
- 독립변수와 종속변수의 관계가 선형이고 독립변수 개수가 하나면 단순선형회귀분석,
  독립변수 개수 2개 이상이면 다중선형회귀분석임

단순선형회귀분석
- 회귀식: yi = b0 + b1xi+ei
- yi: i번째 종속변수값, xi: i번째 독립변수값
- b0: y절편으로 x=0일때 y의 값
- b1: 기울기로 x가 1변할때 y의 변화량
- ei: i번째 오차항(단, N(0,o^2))
- 회귀식을 찾기 위해 최소제곱법(최소자승법)을 이용해 오차 제곱합이 최소가 되는 회귀선
  찾음
- 선형성
  - 독립변수와 종속변수가 선형적이여야 한다는 특성
  - 독립변수의 변화에 따라 종속변수가 일정 크기로 변화
  - 선형성을 만족하려면 잔차들의 평균값은 일정해야 함
  - 정상적이라면 잔차 평균은 0으로 일직선이 되며 비정상적이라면 U자 형태 모양 나옴
- 독립성
  - 단순선형회귀분석에서 잔차와 독립변수의 값 서로 독립적이어야 함
  - 다중선형회귀분석에서 독립변수 간 상관성 없어야 함
- 등분산성
  - 잔차의 분산이 독립변수와 무관하게 일정해야 함
  - 잔차는 표본집단에서 회귀식으로 예측한 값과 실제값과의 차이를 말함
  - 등분산성이 있다면 잔차가 고르게 분포되어야 하며 비정상적이라면 나팔 혹은
    깔때기 모양이 나옴
- 비상관성
  - 관측값과 잔차는 서로 상관이 없어야 한다는 특성
- 정상성
  - 잔차항이 정규분포의 형태를 이뤄야 한다는 특성
 
다중선형회귀 분석
- 회귀식: Y=b0+b1x1+b2x2+...+bkxk+e
- Y: 종속변수 행렬 / x1,x2...xk: 독립변수 행렬
- b0: y절편으로 x=0일때 y의 값
- b1b2...bk: 독립변수 기울기
- e: 오차항(단, N(0,o^2), 서로 독립)
- 다중공선성은 회귀분석에서 독립변수들 간 강한 상관관계가 나타나는 문제
- 다중회귀분석에서 독립변수들 사이에 선형 관계가 존재하면 회귀 계수의 정확한
  추정 난해함
- 분산팽창요인
  - 1에 가까울수록 다중공선성이 낮고 4보다 크면 다중 공선성이 존재
  - 10보다 크면 심각한 문제가 있는 것으로 해석
- 상태지수
  - 10이상이면 문제가 있고 30보다 크면 심각한 문제가 있다고 해석

12주차 pdf 1차 문제 정답: 1, 1(다중회귀모형 통계적 유의성 확인 방법), 1(회귀분석 문제점 발생 현상), 후진제거법(다중 회귀의 단계적 변수 선택 설명)


## 통계분석(2)

회귀분석 모형 구축
- 선형 회귀 분석은 lm함수를 사용해 분석
- lm(formula, data)
  - formula
    - 회귀식의 종속변수, 독립변수 지정
    - 종속변수~독립변수 형태로 지정
    - 다중회귀분석은 독립변수 여러 개 지정
    - 예) Salary ~ Experience+Major
  - data
    - 데이터 프레임 명
- lm함수를 적용하면 summary 정보가 제공됨
  - Estimate(추정값)
    - 독립변수에 대한 회귀계수 추정값
  - Std, Error(표준오차)
    - 독립변수에 대한 측정값의 표준편차
    - 표준오차가 작을수록 추정값과 관측값 차이가 작음
  - t value(t-값)
    - 독립변수와 종속변수 간 선형관계가 존재하는 정도를 나타낸 통계량
    - t값의 절대값이 클수록 독립변수가 종속변수에 유의함
  - Pr(>|t|) (p-값)
    - p-값(유의확률)이 작을수록 독립변수가 종속변수에 유의함
    - 예시) 0.01 ~ 0.05(*), 0.001~0.01(**)

회귀분석 평가
- 회귀분석은 회귀계수 검정, 회귀모형의 설명력, 적합도 검증 및 통계적 유의성 검증으로
  모형 평가
- 잔차의 표준오차
  - 관측값들이 실제 회귀선으로부터 떨어진 정도 나타내는 통계량
- 결정계수(R^2)
  - 전체 데이터를 회귀모형이 얼마나 잘 설명하고 있는지를 보여주는 통계량
  - 결정계수를 통해 추정된 회귀식이 얼마나 타당한지를 검토
  - 값이 1에 가까울수록 회귀모형이 자료를 잘 설명함
- 수정된 결정계수
  - 독립변수의 개수가 많아짐에 따라 무조건 증가하는 결정계수의 문제점을 보완한 통계량
  - 설명력이 떨어지는 독립변수가 추가할 때는 값이 감소하는 특징이 있음
- F-통계량
  - 모형 통계적 유의성 판단
  - F-통계량의 p-값이 0.05보다 작으면 회귀모형은 통계적으로 유의
  - 귀무가설(H0): b1 = b2 = ...=bk = 0
  - 대립가설(H1): b1~bk 중에서 적어도 하나는 0이 아니다.
- 회귀분석의 분산분석표
  - 사진
- 결정계수 R^2 = SSR/SST = 280/1000으로 회귀변동/전체변동으로 구해짐

정규화 선형회귀
- 정규화 선형회귀는 선형회귀계수에 대한 제약 조건 추가해 모형이 과도하게 최적화되는
  과대 적합을 막는 방법
- 선형회귀의 과적합 문제 해결하는 정규화 방법에 라쏘 회귀, 릿지 회귀, 엘라스틱이 있음
- 라쏘 회귀: 기존 함수에 모든 가중치들의 절대값 합계를 추가해 값이 최소가 되도록 함
- 릿지 회귀: 기존 함수에 모든 가중치들의 제곱합을 추가
- 엘라스틱 넷: 기존 함수에 거리측정 규제를 추가함

변수 선택 기법
- 데이터의 독립변수 중 종속변수에 가장 관련성 높은 변수만 선정
- 변수 선택은 step 함수 사용하고 direction 옵션 통해 선택 가능
- AIC를 기준으로 모델 선택(AIC: 적합성 비교지수로 낮을수록 좋음)
- 전진 선택법
  - 모형을 가장 많이 향상시키는 변수를 하나씩 점진적으로 추가하는 방법
  - 변수 추가 시 선택기준이 향상되지 않을 때 변수 추가를 중단
- 후진 제거법
  - 변수 모두 포함한 상태에서 시작하며 가장 적은 영향 주는 변수부터 하나씩 제거하는
    방법
- 단계적 방법
  - 전진 선택법과 후진 제거법을 함께 사용
- step 함수는 AIC가 작아지는 방향으로 단계적으로 변수 선택하는 함수로 AIC가 가장 작은
  값을 가지도록 하는 변수 제거
- step(object, scope, direction)
  - object: 대상 객체
  - scope: 탐색할 모델의 범위 지정
  - direction: forward = 전진선택법, backward=후진 제거법, both=단계적 방법
- formula함수는 step함수를 수행한 뒤 반환 값을 변수로 전달받아 표물러('종속변수~
  독립변수'형태)를 구하는 함수
- formula(x)
  - x: step 함수의 반환 값을 입력


## 통계분석(3)

상관분석
- 두 변수 사이 어떤 선형적 또는 비선형적 관계가 있는지 분석하는 방법
- 상관분석 통해 두 변수 사이 인과관계는 확인할 수 없음

상관관계의 분류
- 분석이 되는 변수 속성에 따라 수치적 데이터, 명목적 데이터, 순서적 데이터 등으로
  분류할 수 있음
- 수치적 데이터
  - 수치로 표현할 수 있는 측정 가능한 데이터 변수
  - 예) 키, 몸무게, 나이 등
  - 피어슨 상관계수 사용
- 명목적 데이터
  - 데이터의 특성을 구분하기 위해 숫자나 기호 할당한 데이터 변수
  - 예) 성별(남/여), 만족도(1~5점)
  - 카이제곱 검정
- 순서적 데이터
  - 데이터의 순서에 의미 부여한 데이터 변수
  - 예) 성적 순위
  - 스피어만 순위상관계수

상관계수
- 두 변수 사이 연관성을 수치상으로 객관화해 두 변수 사이 방향성과 강도 표현 방법
- 상관계수만으로 통계적 유의성을 확인할 수 없음
- 상관계수는 -1~1의 값을 가지며 -값을 가지면 음의 상관관계, +값을 가지면 양의
  상관관계임

공분산
- 공분산은 2개 변수 사이 관련성을 나타내는 통계량
- 상관계수의 상승 혹은 하강하는 경향 파악 가능
- 공분산 값의 크기는 측정 단위에 따라 달라지므로 선형관계의 강도 나타내지 못함
  - Cov>0: 두 변수 중 하나의 값 상승 시 다른 값도 상승
  - Cov=0: 두 변수 간 아무런 선형 관계가 없고 독립적인 관계
  - Cov<0: 두 변수 중 하나 값 상승 시 다른 값 하강

주성분 분석
- 주성분 분석은 상관관계가 있는 고차원 자료를 자료의 변동을 최대한 보존하는 저차원
  자료로 변환하는 차원 축소 방법
- 주성분 분석은 서로 상관성이 높은 변수들의 선형 결합을 만들어 기존 상관성 높은 변수들
  요약, 축소하는 기법
- 차원의 축소는 주성분 분석에서 변수의 중요도 기준이 되는 고유값을 정렬해 높은 고유값
  가진 고유벡터만으로 데이터 파악

주성분 분석 구성
- 제1주성분
  - 전체 데이터 가장 폭넓게 설명할 수 있는 성분으로 분산이 가장 큰 방향에 대한 변수들
    의 선형 결합
- 제2주성분
  - 제1주성분의 영향을 제거한 데이터 중에서 데이터를 가장 폭넓게 설명할 수 있는 축으로
    제1주성분과 독립임
- 제 k주성분
  - 제1주성분~제k-1주성분의 영향을 제거한 데이터 중 데이터를 가장 폭넓게 설명할 수
    있는 축으로 제1주성분~제k-1주성분과 독립

주성분 분석의 구축
- princomp함수와 prcomp함수를 이용
- princomp(x,cor,...)
  - x: 주성분 분석 대상 데이터
  - cor
    - 공분산 행렬 또는 상관행렬 사용 여부
    - TRUE: 상관계수 행렬 사용(기본값)
    - FALSE: 공분산 행렬 사용
- prcomp(x,scale,...)
  - x: 주성분 분석 대상 데이터
  - scale
    - 변수가 단위 분산을 갖도록 해야 하는지 여부
    - TRUE: 상관계수 행렬 사용
    - FALSE: 공분산 행렬 사용(기본값)

주성분 분석의 해석
- Standard Deviation(표준편차)
  - 주성분들의 표준편차
- Proportion of Variance(분산비율)
  - 주성분들이 차지하는 비율
  - 분산비율 = (주성분 분산)/(전체 분산)
  - 값이 클수록 영향도가 높음
- Cumulative Proportion(누적비율)
  - 분산의 누적 합계

적재값
- 주성분 분석 결과 통해 각 주성분 적재값 알 수 있음
- 주성분 값: sigma(n, i=1){(적재값 * 변수} (단, n은 변수 개수)
- 변수값: sigma(n, i=1){(적재값 * 주성분} (단, k는 주성분 개수)

주성분 개수 선택 방법
- 전체 변이 공헌도
  - 주성분들이 설명하는 총 분산의 비율이 70~90% 사이가 되는 주성분 개수 선택
- 스크리 산점도
  - x축에 주성분, y축에 각 주성분의 분산 표현한 그래프
  - 기울기가 완만해지기 직전까지를 주성분 수로 결정함
- 평균 고유값
  - 고유값들의 평균을 구한 후 고유값이 평균값 이상이 되는 주성분을 선택하는 방법
