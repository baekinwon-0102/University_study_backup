공공데이터와 OpenAPI
- 공공데이터란 공공기간이 만들어내는 모든 자료나 정보
- 공공데이터는 "공공데이터포털"을 통해서 파일 다운로드나 Open API형태로 활용
- OpenAPI(Open Application Programming Interface, 공개 API)란
  누구나 사용할 수 있도록 공개된 API
- API란 두 애플리케이션 간 요청과 응답을 사용해 서로 통신하는 방법(형식)을 정의

API 형식 확인
- API를 사용하려면 API 문서 확인 필요
- API 문서는 API가 제공하는 기능, 사용방법, 요청 및 응답형식 등 필요한 모든 정보 담고
  있음
- API 문서를 통해 어떤 API를 사용해야 하는지, 어떻게 사용해야 하는지, 어떤 데이터
  요청하고 응답으로 받는지 등을 정확하게 파악 가능

JSON
- 가독성이 뛰어난 데이터 교환 형식
- 프로그래밍 언어나 플랫폼에 독립적, 프로그래밍 언어에서 쉽게 이용
- 구조 간단해 데이터 크기 작음
- 키-값 쌍으로 이루어져 있음

XML
- 마크업 언어
- 스키마 지원으로 문서의 의미와 구조를 함께 저장할 수 있음
- 문서중심 데이터 교환에 유리
